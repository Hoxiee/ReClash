# 自动路由中心

路由中心是自动路由的主页面。打开**高级设置** → **自动路由**。页面包含三个选项卡：**概览**、**路由**和**库**。可使用顶部切换控件或滑动切换。应用会记住上次打开的选项卡。宽窗口中的标题为“自动路由”、一个圆点和选项卡名称。

右上角的三点菜单包含**新建场景**、**新建配置**和**导入**。

> [!NOTE]
> **截图 `hub-menu`** —— 路由中心顶部菜单展开，显示“新建场景”“新建配置”和“导入”。

## 概览选项卡

概览用于回答“自动路由现在在做什么”。

> [!NOTE]
> **截图 `hub-overview`** —— 自动路由已启用，“我的分流”场景正在运行，显示实时状态、路由、智能组和能耗统计。

### 首次显示前

| 显示内容 | 原因 | 操作 |
| --- | --- | --- |
| **没有订阅**，并提示“请先添加订阅；自动路由使用订阅中的组”。 | 尚未选择配置。 | 添加订阅。 |
| **启动连接以查看自动路由** | Core 未运行，没有实时数据。 | 启动连接。 |

> [!NOTE]
> **截图 `hub-no-subscription`** —— 概览选项卡处于“没有订阅”状态。

### 开启自动路由

1. 打开**自动路由** → **概览**。
2. 开启**自动路由**。

应用会启动上次选择的场景。如果从未选择过场景，则启动内置场景**所有组**，使订阅中的每个 select 组都成为智能组。关闭开关时，页脚显示：“开启后，场景会为你的组和路由选择服务器”。

> [!NOTE]
> **截图 `hub-overview-off`** —— 概览页面的总开关关闭，并显示提示。

如果场景存在问题（例如需要授权），开关下方会显示问题文本而不是普通说明。

### 选择场景

场景卡片显示当前运行场景的标题和说明。点按**更改**。

> [!NOTE]
> **截图 `scenario-chooser`** —— 场景选择面板分为“我的”“来自服务商”“内置”，显示标题和说明，并选中“我的分流”。

场景按来源分组：

| 分区 | 内容 |
| --- | --- |
| **我的** | 你创建或另存为副本的场景。 |
| **来自服务商** | 订阅提供的场景。 |
| **内置** | 随 ReClash 提供的场景，例如“所有组”。 |

点按场景即可运行。选择场景不会修改它；编辑方式见[创建自己的副本](#创建自己的副本)。

### 实时状态行

卡片下方显示**网络：<kind> · 模式：<mode>**。副标题说明当前模式由谁决定：

| 副标题 | 含义 |
| --- | --- |
| 场景在此网络下设置模式 | 模式由场景选择。 |
| 此网络下的模式由你决定 | 场景将模式交给用户。 |
| 你手动选择了模式；场景会等待你选择 Auto | 用户手动覆盖了模式。 |

手动覆盖模式后，会显示**恢复自动**一行（“将模式控制权交还场景”）。点按后场景会重新决定模式。场景有问题时不显示实时状态行。

### “路由”和“智能组”列表

**路由**区域为运行场景中的每条路由显示一行。副标题包含：

- 路由问题（如有，参见[故障排查](troubleshooting.md)）；
- 直连路由显示**直连**；固定路由显示目标；
- 其他路由显示当前服务器、所在国家（名称中无旗帜时）、延迟和步骤。

点按路由可打开[组面板](groups.md)；直连路由和固定路由没有组面板。

**智能组**区域列出自动路由控制的其他组，副标题格式相同。执行过检查后，页脚显示 **今日检查：{requests} · 已用 {used}/{cap}**；否则显示“自动路由尚未控制任何组”。能耗行显示今日探测请求数和每日上限。

> [!NOTE]
> **截图 `hub-groups-energy`** —— 智能组列表包含多行，并在底部显示“今日检查”。

### 授权

如果场景或配置需要访问网站，页面顶部会显示**需要授权**区域。参见[groups.md#consent](groups.md#授权)。

## 路由选项卡

路由选项卡用于编辑当前场景的路由。

> [!NOTE]
> **截图 `hub-routes`** —— “我的分流”的路由页面，包含四条路由、“添加路由”、“其他流量”、“其他组”和“网络”。

### 空状态

| 状态 | 显示内容 | 操作 |
| --- | --- | --- |
| 没有运行场景 | **没有运行场景**：“路由会将选定流量（例如某个服务）通过专属服务器发送。” | **启动场景**会创建并运行一个标题为“新建场景”的自有场景。 |
| 当前不是 rule 模式 | 警告：“路由仅在 rule 模式下生效；当前连接使用 {mode} 模式。” | 将连接切换到 rule 模式。 |

> [!NOTE]
> **截图 `hub-routes-off`** —— 路由选项卡显示“没有运行场景”和“启动场景”按钮。

> [!NOTE]
> **截图 `hub-routes-rule-only`** —— 连接处于 global 模式时，路由选项卡页脚显示 rule 模式警告。

### 路由卡片

**路由**区域中每条路由显示名称、流量简述（名称已说明时会隐藏）和服务器设置摘要（例如“直连”“通过 X”或服务器顺序）。页脚提示：“流量从上到下采用第一个匹配的路由”。

| 操作 | 功能 |
| --- | --- |
| 点按路由 | 打开[路由编辑器](routes.md#路由编辑器)。 |
| 长按（桌面端右键） | 菜单包含**编辑**和**删除**。 |
| **添加路由**行 | 开始[添加路由流程](routes.md#为单个服务添加路由)。 |
| 标题栏排序按钮（至少两条路由时显示） | 进入排序模式；拖动行后退出。 |

顺序很重要：流量匹配两条路由时，靠上的路由优先。

> [!NOTE]
> **截图 `hub-routes-reorder`** —— 路由列表处于排序模式，显示拖动手柄。

### 其他流量

此行匹配任何未被路由接管的流量。说明文字为：“未匹配路由的流量通过订阅主组。”行中会显示主组名称（或“主组”），以及“组自身配置”或你设置的服务器顺序摘要。点按可为主组设置独立行为和服务器顺序。“我的分流”示例中可在此设置“主流量走挪威”。

> [!NOTE]
> **截图 `hub-everything-else`** —— “其他流量”行及仅含“国家：挪威”一步的编辑器。

### 其他组

**其他组**（“此场景还控制的订阅组”）可以为指定组和**所有组**（`*` 规则）设置规则。使用**添加组**菜单为组或剩余所有组添加规则；长按一行可**删除**。编辑方式与路由的服务器顺序相同，但不包含流量条件。

> [!NOTE]
> **截图 `hub-other-groups`** —— “其他组”区域显示一条“所有组”规则和“添加组”菜单。

### 网络

可展开的**模式和网络**一行（副标题“此场景的行为”）包含：

| 项目 | 含义 |
| --- | --- |
| **连接模式** | 场景是否更改模式：保持不变、rule、global 或 direct。 |
| 网络类型 | 网络类型名称（例如“home”）；每项可设置**识别条件**、该网络下的模式及组规则。 |
| **添加网络类型** | 最多 24 个字符，只能使用小写拉丁字母、数字和连字符。 |
| **标签** | 供步骤通过 `tag(name)` 使用的服务器集合名称。最多 24 个字符，可用字母、数字、`-`、`_`。 |
| **高级** | 网络诊断和翻译；此处只读，提示“这些部分通过 YAML 编辑”。 |

文本格式见[scenarios.md](../scenarios.md)。

> [!NOTE]
> **截图 `hub-networks`** —— 展开的网络区域包含连接模式、网络类型、标签和高级设置。

### 创建自己的副本

内置场景和服务商场景不可直接修改。首次尝试编辑（例如添加路由）时，ReClash 会询问：

> **创建自己的副本？** “‘{title}’不是你的场景，无法直接修改。你的编辑会保存到副本，并由副本成为当前运行场景。”

选择**创建副本**。副本会放入**我的**并立即运行，同时保留来源链接，方便之后[合并原始场景的更改](studio.md#合并原配置的更改)。

> [!NOTE]
> **截图 `copy-dialog`** —— “创建自己的副本？”对话框和创建按钮。

### 自动保存与版本

自己的场景在内容有效后会立即保存。应用会为每个场景保留最近 10 个版本，但只有配置工作台支持恢复版本（参见[studio.md#history-and-restore](studio.md#历史记录和恢复)）。路由编辑后，稍等片刻会重新应用一次配置。

## 关闭自动路由

### 对整个订阅关闭

1. 打开**自动路由** → **概览**。
2. 关闭**自动路由**。

当前场景会被清除。组恢复为普通 select 组，当前服务器保持不变。场景仍保留在库中。

### 对单个组关闭

1. 打开“代理”并点按组，再打开其自动路由面板。
2. 滚动到底部并点按**关闭自动路由**。

这会移除组自身的绑定。只有由你配置为智能组的条目显示此选项；由场景控制的组不显示。参见[groups.md#turn-auto-routing-off-for-one-group](groups.md#关闭单个组的自动路由)。

### 删除单条路由

1. 打开**路由**选项卡。
2. 长按路由并选择**删除**。

路由及其组会消失；对应流量会匹配下一条路由或进入**其他流量**。

> [!NOTE]
> **截图 `route-delete-menu`** —— 路由上下文菜单显示“编辑”和“删除”。

## 操作示例：从空白状态创建“我的分流”

目标设置（参见[演示配置](../images/README.md#演示设置)）：

- 主流量走挪威；
- YouTube 使用 ⚡ RU 服务器，否则任意可用服务器；
- Claude 走瑞典；
- Gemini 使用名称中带 `*` 的任意服务器；
- Local 将 `category-ru` 和 `yandex` 网站类别直连。

1. 打开**高级设置** → **自动路由** → **路由**选项卡。显示**没有运行场景**。
2. 点按**启动场景**。新建的“新建场景”场景开始运行。
3. 点按**添加路由**。（最后再将场景命名为“我的分流”。）
4. 选择 **YouTube** 服务标签并点按**下一步**。名称会预填“YouTube”和 emoji；保留该名称，**流量通过**保持为 **Auto**。
5. 在**服务器顺序**中点按**添加步骤**。在**此步骤中的服务器**下点按**名称包含**并输入 `⚡ RU`，然后确认。页脚会显示匹配的服务器数量。
6. 再次添加步骤，所有字段留空；步骤显示为**任意可用服务器**。保存路由。
7. 添加 **Gemini** 路由，重命名为“✨ Gemini”。新增一步，设置**名称包含**为 `*`；此处星号是普通字符，不是通配符。
8. 添加路由，不选服务标签，改为点按**添加条目** → **网站类别**，输入 `category-ru`。再添加**域及其子域**条目，输入 `yandex.ru`。点按**下一步**，命名为“🏠 Local”，将**流量通过**设为**直连**。
9. 添加 Claude 路由：选择 **Claude** 服务标签（改名为“🤖 Claude”），新增一步并将**国家**设为瑞典。
10. 使用排序操作调整顺序。具体的路由应排在范围更广的路由之前。
11. 打开**其他流量**并添加一步，将**国家**设为挪威。
12. 打开**库**，点按“新建场景”，输入标题 `我的分流` 和说明并保存。
13. 检查**概览**选项卡，确认路由显示了当前服务器。
