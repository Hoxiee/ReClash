# 组面板

组面板用于查看和控制单个组。它位于**代理**页面：选择一个组（只有 select 组有此面板），点按顶部栏的**自动路由**按钮，或在该组的行中执行相同操作。也可从路由中心的组行打开。面板标题为组名。

从上到下的区域（部分区域仅在有内容时显示）：

1. 红色问题提示，例如配置缺失。
2. 配置等待授权时显示**需要授权**。
3. 状态卡片和**更换服务器**。
4. **控制方式**。
5. **更改为**。
6. **行为**。
7. **为何选择此服务器**。
8. **历史记录**。
9. **自动路由设置**。
10. **由路由创建**或**关闭此组的自动路由**。

> [!NOTE]
> **截图 `group-sheet-auto`** —— 主组处于 Auto 控制时的面板：状态卡片、控制方式、“更改为”选项和行为区域。

## 尚未启用自动路由的组

未启用自动路由的组会显示简要说明、**开启自动路由后**区域（默认配置及其说明、服务器数量）和一个实心按钮。

1. 打开组面板。
2. 阅读提示：“ReClash 会在此组中保留可用服务器，服务器故障时自动切换。只有在使用网络时才会执行检查。”
3. 点按**开启自动路由**。

此操作会为组创建自身绑定，并使用默认配置。撤销方法见[关闭单个组的自动路由](#关闭单个组的自动路由)。

> [!NOTE]
> **截图 `group-intro`** —— 尚未开启自动路由的组面板，显示“开启自动路由”按钮。

## 状态卡片

顶部卡片显示：

| 部分 | 含义 |
| --- | --- |
| 服务器名称 | 当前服务器；若名称中没有国旗，会在前方补充国旗。 |
| 原因 | 选择此服务器的原因，例如“可用；故障前保持使用”。原因代码见[troubleshooting.md](troubleshooting.md#状态卡片中的原因)。 |
| 预测 | 可能发生的后续操作，例如“可能在 {minutes} 分钟后切换到 {node}”、“检查确认后将切换到 {node}”或“若优势保持在 {gain} ms，将切换到 {node}”。 |
| 详情 | 国家、步骤名称和“网络：{kind}”，以“·”分隔。 |
| 延迟 | 已知时在右侧显示，单位为 ms。 |
| **更换服务器** | 卡片下方的按钮。切换到表现最佳的其他服务器，并在 15 分钟内跳过当前服务器。Manual 模式下禁用。 |

## 控制方式：Auto、Pinned、Manual

**控制方式**是三段式选择器，下方说明所选模式。

| 选项 | 提示 | 行为 |
| --- | --- | --- |
| **Auto** | 按服务器顺序选择最佳可用节点，节点故障时自动切换。 | 由行为配置决定。 |
| **Pinned** | 保持使用 {node}；仅在其故障时离开，恢复后再切回。 | 固定当前服务器（必须已选中一个）。若它故障，自动路由会离开它，并在恢复后切回。 |
| **Manual** | 在代理列表中自行选择服务器；自动路由不会切换。 | 你在组列表中选择服务器；自动路由只负责监控。 |

点按 **Auto** 可恢复自动模式。固定期间在**更改为**中选择节点池也会恢复 Auto。

> [!NOTE]
> **截图 `group-sheet-pinned`** —— 控制方式为 Pinned，状态卡片显示“保持固定服务器”。

## 更改为

当组被固定到一个成员时，此区域隐藏（行为行会显示“通过 {member}”）。点按一次即可缩小组的节点池，并切换到其中最佳服务器。Manual 模式下，选项和加号按钮不可用。

| 控件 | 功能 |
| --- | --- |
| **任意**选项 | 不缩小节点池。 |
| 各选项 | 服务商提供的节点池、你创建的节点池，以及服务器名称中识别出的国旗。只有服务器来自至少两个国家时才显示国旗选项；按出现频率从高到低排列，最多 8 个。 |
| **添加名称模式**（加号按钮） | 输入**名称模式**（正则表达式，不区分大小写地匹配服务器名称）。对话框显示“匹配 {count}/{total} 个”；无匹配或格式无效时不能提交。新选项会立即选中。 |
| 长按（或右键点击）自定义选项 | **删除**。服务商选项和国旗选项没有菜单。 |

> [!NOTE]
> **截图 `group-change-to`** —— “更改为”区域包含 Any、🇳🇴、🇸🇪、🇷🇺 和一个自定义模式。

## 行为区域

| 行 | 打开内容 |
| --- | --- |
| 配置行（标题及说明或 **Simple**/**Advanced** 级别） | **配置**选择器，分为**内置**、**来自服务商**和**我的**。每个配置显示说明；需要授权时会显示“需要授权”。服务商组只列出服务商提供的配置。页脚说明可在“高级设置”→“自动路由”中创建配置。 |
| **服务器顺序** | 该组自身的服务器顺序页面（固定到单个成员时隐藏）。副标题是概要，例如“1 ⚡ RU → 2 任意可用服务器”。参见[服务器顺序页面](#服务器顺序页面)。 |
| **组设置** | [设置页面](#设置页面)，副标题为“切换：… · 检查：…”。 |

若配置存在问题，区域底部会显示问题；若场景正在控制该组，则显示“场景‘{scenario}’当前正在控制此组”。当场景程序针对的是其他目标（例如主组或所有组）时，配置行也会显示其目标。

服务器顺序优先级从高到低：场景给该组设置的顺序、你为组设置的顺序、配置自身的顺序。最后回退步骤会让位于所有其他步骤，包括排在它后面的步骤。

> [!NOTE]
> **截图 `group-behaviour`** —— 行为区域显示 Fastest 配置、服务器顺序概要和设置入口。

## 服务器顺序页面

页面标题为**服务器顺序**，顶部显示组名。此处编辑组自己的服务器顺序，使用与路由相同的[步骤编辑器](routes.md#服务器顺序编辑器)。

- 如果尚未设置自定义步骤，页面会将配置中的步骤灰显，并提示“来自行为——编辑步骤以设置自己的顺序”。编辑或新增步骤时会以这些步骤的副本为起点。删除所有步骤后即可再次跟随配置。
- 每行包含步骤编号、标签或条件、可选的“最后回退”标志以及匹配服务器数量（“{count} 个服务器”，为 0 时显示红色）。当前服务器所属步骤会高亮。
- “如果都不可用”说明连接第 1 步和第 2 步。
- 加号按钮（**添加步骤**）新增步骤。两个或更多步骤时，可通过排序按钮拖动调整顺序。长按（或右键）步骤可选择**删除**。
- 页脚显示：“此顺序仅用于该组。留空即可跟随配置中的服务器顺序。”若场景正在控制该组，则改为：“场景当前控制此组：场景指定的服务器顺序优先于此顺序。”

## 设置页面

> [!NOTE]
> **截图 `group-settings`** —— 设置页面包含名称模式“匹配 4/5”、Balanced 切换策略、Economical 检查级别和直连网站开关。

| 区域 | 控件 | 说明 |
| --- | --- | --- |
| **服务器** | **名称模式** | 正则表达式（提示“任意”），按 Enter 后应用，且仅接受有效表达式。留空表示任意服务器。页脚显示“匹配 {count}/{total} 个”或“模式不是有效的正则表达式”。 |
| **行为** | **切换策略** | **很少**、**平衡**、**频繁**。决定从可用服务器切换到更优服务器的积极程度。 |
| | **检查** | **省流量**、**平衡**、**精确**。决定可使用多少探测请求。 |
| **网络** | **通过此组连接直连网站** | “按规则直连的网站无法打开时，通过此组连接。局域网地址始终保持直连。”仅支持此功能的组显示此选项。开启后会显示**当前已启用**或**已就绪：直连网站仍可打开**。 |

## 为何选择此服务器与历史记录

当引擎已有排序结果时，会显示可展开的**为何选择此服务器**。折叠时显示“比较了 {count} 台服务器”；展开后最多显示 8 台服务器。每行显示服务器和延迟，当前服务器会高亮。名称下方的信息包括：

- 排除原因，或步骤及服务器状态；
- 如果检查可能提升优先级，则显示“检查后可能进入‘{tier}’”；
- 已验证的出口国家：“出口 {flag} {code}”；
- 检查结果标记：✓ 通过、× 失败、~ 软失败；
- 距上次检查的时间。

被排除的服务器会显示以下原因之一：不在节点池、配置排除、不是服务器、因“更换服务器”而跳过、没有匹配的偏好、尚未检查。状态显示为**可用**、**曾经可用**、**未检查**或**不可用**。

> [!NOTE]
> **截图 `group-why`** —— 展开的“为何选择此服务器”包含五行，其中一行为“因更换服务器而跳过”。

有至少一条事件后才会显示可展开的**历史记录**。折叠时显示最近一条；展开后显示最近 20 条，按时间从新到旧排列并标注时间：

- 切换：“{from} → {to}: 原因”；
- 故障：“{node} 已停止工作”；
- 固定：“已固定：{node}”；
- 模式变化：“模式 {from} → {to}”。

> [!NOTE]
> **截图 `group-history`** —— 展开的历史记录中有一条故障切换和一条固定记录。

## 自动路由设置

**自动路由设置**行（“配置、场景和路由”）会关闭组面板并打开[路由中心](hub.md)。若从路由中心打开此面板，则只会关闭面板。

## 授权

部分配置需要访问网站来执行检查。在你允许之前，组会使用 Simple。

1. 打开组面板。顶部的**需要授权**区域会显示“‘{profile}’希望检查以下网站”，并列出主机。
2. 点按**允许**。

页脚说明：“允许之前，组会使用 Simple 配置。访问网站仅通过你的服务器，或用于检查网络。”

路由中心也会为场景显示相同区域，参见[hub.md#consent](hub.md#授权)。

> [!NOTE]
> **截图 `group-consent`** —— “需要授权”区域列出主机，并显示“允许”操作。

## 路由组

由路由创建的组会显示**由路由创建**区域，而不是关闭自动路由的选项。**编辑路由**行显示：“场景‘{scenario}’中的路由创建了此组。请前往该场景编辑或删除路由。”右侧带有展开箭头。点按后会关闭组面板，并在路由中心的“路由”选项卡中打开对应路由（高级设置 → 自动路由）。

> [!NOTE]
> **截图 `group-route`** —— 名为“▶️ YouTube”的组面板，显示“由路由创建”区域。

## 关闭单个组的自动路由

1. 打开组面板。
2. 滚动到底部，点按红色的**关闭此组的自动路由**。

此操作会移除此组自身的绑定。页脚显示：“该组会保留当前服务器，并停止自动切换。”只有组自身有绑定时才显示此行；路由组不会显示此项。如果场景仍在控制该组，应改为修改场景（参见[hub.md#turn-auto-routing-off](hub.md#关闭自动路由)）。
