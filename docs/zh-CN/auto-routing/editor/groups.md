# 组面板

组面板用于查看和控制单个组。它位于**代理**页面：选择一个组（只有 select 组有此面板），点按顶部栏的**自动路由**按钮，或在该组的行中执行相同操作。也可从自动路由页面的组行打开。面板标题为组名。

从上到下的区域（部分区域仅在有内容时显示）：

1. 红色问题提示，例如配置缺失。
2. 配置等待授权时显示**需要授权**。
3. 状态卡片和**更换服务器**。
4. **控制方式**。
5. **行为**、**服务器顺序**、**服务器**、**切换**和**检查频率**。
6. **网络**（仅支持直连网站的组）。
7. **详情**。
8. **自动路由设置**。
9. **由路由创建**或**关闭此组的自动路由**。

## 尚未启用自动路由的组

未启用自动路由的组会显示简要说明、**开启自动路由后**区域（默认配置及其说明、服务器数量）和一个实心按钮。

1. 打开组面板。
2. 阅读提示：“ReClash 会在此组中保留可用服务器，服务器故障时自动切换。只有在使用网络时才会执行检查。”
3. 点按**开启自动路由**。

此操作会为组创建自身绑定，并使用默认配置。撤销方法见[关闭单个组的自动路由](#关闭单个组的自动路由)。

## 状态卡片

顶部卡片显示：

| 部分 | 含义 |
| --- | --- |
| 服务器名称 | 当前服务器；若名称中没有国旗，会在前方补充国旗。 |
| 原因 | 选择此服务器的原因，例如“可用；故障前保持使用”。原因由引擎的排序给出，见[引擎](../engine.md)。 |
| 预测 | 可能发生的后续操作，例如“可能在 {minutes} 分钟后切换到 {node}”、“检查确认后将切换到 {node}”或“若优势保持在 {gain} ms，将切换到 {node}”。 |
| 详情 | 国家、步骤名称和“网络：{kind}”，以“·”分隔。 |
| 延迟 | 已知时在右侧显示，单位为 ms。 |
| **更换服务器** | 卡片下方的按钮。切换到表现最佳的其他服务器，并在 15 分钟内跳过当前服务器。Manual 模式下禁用。 |

## 控制方式：Auto、Pinned、Manual

**控制方式**是三段式选择器，下方说明所选模式。

| 选项 | 提示 | 行为 |
| --- | --- | --- |
| **Auto** | 按服务器顺序选择最佳可用节点，节点故障时自动切换。 | 由行为配置决定。 |
| **Pinned** | 保持使用 {node}；仅在其故障时离开，恢复后再切回。 | 固定当前服务器（必须已选中一个）。若它故障，自动路由会离开它，并在恢复后切回。 |
| **Manual** | 在代理列表中自行选择服务器；自动路由不会切换。 | 你在组列表中选择服务器；自动路由只负责监控。 |

点按 **Auto** 可恢复自动模式。固定期间在**服务器**中选择节点池也会恢复 Auto。

## 组如何选择服务器

这是查看和修改组如何选择服务器的唯一位置。每一行都会注明取值来源：**来自场景「{scenario}」**、**此分组的自定义设置**或**来自行为「{behaviour}」**。固定到单个成员的组只显示**经由 {member}**。

| 行 | 编辑内容 |
| --- | --- |
| **行为** | `profile`；在**内置**、**来自服务商**和**我的**中选择，场景程序中还有**按分组中的设置**。 |
| **服务器顺序** | `prefer`，使用[步骤编辑器](routes.md#服务器顺序编辑器)。留空则跟随行为。 |
| **服务器** | 节点池，见下文。 |
| **切换** | `feel`：**很少**（`calm`）、**平衡**、**频繁**（`eager`）。 |
| **检查频率** | `energy`：**省流量**、**平衡**、**精确**。 |

### 更改保存在哪里

更改保存到已设置该字段的层：运行中场景针对此组的程序（或其路由），否则保存到用户绑定。在场景的**所有组**程序（`*`）下，修改的字段会创建以该组名命名的程序，而不是修改所有组。内置或服务商场景会先复制到**我的**，再进行首次更改。**切换**和**检查频率**始终保存到绑定。

### 服务器

**服务器**行会打开**选择范围**；每个选择都会设置 `pool.include`，并让被固定的组恢复 Auto。

| 部分 | 节点池 |
| --- | --- |
| **任意** | 不缩小节点池。 |
| 服务商和自定义选项 | 绑定的 `chips`。 |
| 国旗 | 服务器名称中识别出的国旗，至少两个国家时显示，按出现频率排列，最多 8 个。 |
| **名称模式** | 保存为 `name ~ /pattern/i`；格式无效或无匹配时不接受（“匹配 {count}/{total} 个”）。 |

长按（或右键点击）自定义选项可**删除**。其下方的**仅服务器**和**排除服务器**会打开[条件构建器](routes.md#条件构建器)。

服务器顺序优先级从高到低：场景给该组设置的顺序、你为组设置的顺序、配置自身的顺序。最后回退步骤会让位于所有其他步骤，包括排在它后面的步骤。

## 为何选择此服务器与历史记录

**详情**行（“比较了 {count} 台服务器”）会打开**为何选择此服务器**和**历史记录**两部分。**为何选择此服务器**最多显示 8 台服务器。每行显示服务器和延迟，当前服务器会高亮。名称下方的信息包括：

- 排除原因，或步骤及服务器状态；
- 如果检查可能提升优先级，则显示“检查后可能进入‘{tier}’”；
- 已验证的出口国家：“出口 {flag} {code}”；
- 检查结果标记：✓ 通过、× 失败、~ 软失败；
- 距上次检查的时间。

被排除的服务器会显示以下原因之一：不在节点池、配置排除、不是服务器、因“更换服务器”而跳过、没有匹配的偏好、尚未检查。状态显示为**可用**、**曾经可用**、**未检查**或**不可用**。

有至少一条事件后才会显示**历史记录**，显示最近 20 条，按时间从新到旧排列并标注时间：

- 切换：“{from} → {to}: 原因”；
- 故障：“{node} 已停止工作”；
- 固定：“已固定：{node}”；
- 模式变化：“模式 {from} → {to}”。

## 自动路由设置

**自动路由设置**行（“配置、场景和路由”）会关闭组面板并打开[自动路由](hub.md)。若从自动路由页面打开此面板，则只会关闭面板。

## 授权

部分配置需要访问网站来执行检查。在你允许之前，组会使用 Simple。

1. 打开组面板。顶部的**需要授权**区域会显示“‘{profile}’希望检查以下网站”，并列出主机。
2. 点按**允许**。

页脚说明：“允许之前，组会使用 Simple 配置。访问网站仅通过你的服务器，或用于检查网络。”

自动路由页面也会为场景显示相同区域，参见[hub.md#consent](hub.md#授权)。

## 路由组

由路由创建的组会显示**由路由创建**区域，而不是关闭自动路由的选项。**编辑路由**行显示：“场景‘{scenario}’中的路由创建了此组。请前往该场景编辑或删除路由。”右侧带有展开箭头。点按后会关闭组面板，并在自动路由页面中打开对应路由（工具 → 自动路由）。

## 关闭单个组的自动路由

1. 打开组面板。
2. 滚动到底部，点按红色的**关闭此组的自动路由**。

此操作会移除此组自身的绑定。页脚显示：“该组会保留当前服务器，并停止自动切换。”只有组自身有绑定时才显示此行；路由组不会显示此项。如果场景仍在控制该组，应改为修改场景（参见[hub.md#turn-auto-routing-off](hub.md#关闭自动路由)）。
