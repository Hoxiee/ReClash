# 组配置工作台

组配置（也称“行为”）决定智能组如何选择服务器。工作台用于编辑配置。可从路由中心进入：打开**库**选项卡，筛选**组配置**，点按自己的配置（点按其他配置会编辑其副本）；也可从三点菜单选择**新建配置**。路由中心位于“高级设置”→“自动路由”。

配置的文本格式见[profiles.md](../profiles.md)。

> [!NOTE]
> **截图 `studio-form`** —— 工作台表单模式显示“常规”“服务器”“服务器顺序”“标签”和“行为”区域。

## 表单和文本

右上角菜单包含 **YAML**。它会在完整编辑器中打开配置文本；保存后会替换表单内容。表单始终反映文本内容。在表单中编辑会根据解析后的内容重写文本，因此手写 YAML 注释不会保留。名称和说明会在停止输入片刻后写入。

应用栏中的勾选按钮用于保存配置。如果顶部横幅有错误，或内容没有变化，该按钮会禁用。

> [!NOTE]
> **截图 `studio-yaml`** —— 配置的 YAML 文本编辑器。

## 表单区域

新配置从模板开始：标题“My profile”、Simple 级别、单个“Working”步骤（`not dead`）、按延迟排序，并将切换设为“很少”。

从上到下包括：错误横幅、**原始配置已更改**（适用时）、**常规**、**服务器**、**服务器顺序**、**标签**、**行为**、**高级**（使用时）、**检查**（存在智能组时）、**警告**、**将访问的网站**。

| 区域 | 控件 | 说明 |
| --- | --- | --- |
| **常规** | **名称** | 配置标题，提示“新建配置”。 |
| | 说明框 | 提示“此配置的作用”。 |
| | **级别** | **Simple** 或 **Advanced**。 |
| | **基于** | 继承配置：**无**或库中的其他配置。 |
| **服务器** | **使用** | 节点池条件，默认“任意服务器”。 |
| | **排除** | 排除条件，默认“无”。 |
| **服务器顺序** | 步骤 | 见下文。 |
| **标签** | **添加标签** | “标签可为一组服务器命名，以便在步骤中通过 tag(name) 使用”。 |
| **行为** | **切换**、**检查**、**没有服务器符合条件时** | 切换和检查与组设置相同（**很少**、**平衡**、**频繁**；**省流量**、**平衡**、**精确**）。无可用服务器时可选**保留当前服务器**或**直连**。 |
| **高级** | 只读 | “这些部分通过 YAML 编辑”。每个使用的部分显示一行：可用性检查、网络类型、按网络覆盖、通过此组直连网站、出口国家检查和翻译。点按一行会打开 YAML 编辑器。 |

### 服务器顺序

工作台使用与组页面相同的阶梯，标题为**服务器顺序**。步骤由上而下排列；第一个包含可用服务器的步骤获胜。前两个步骤之间有“如果都不可用”的说明。列表为空时显示“任意可用服务器”，并提示“添加步骤以优先选择某些服务器”。

- 加号按钮（**添加步骤**）会新增步骤；点按某个步骤可打开路由也使用的[步骤编辑器](routes.md#步骤编辑器)。
- 两个或更多步骤时，可使用排序按钮拖动调整顺序。长按（或右键）步骤可选择**删除**。
- 每步显示标签或条件；启用时显示“最后回退”；若工作台针对组检查，还会显示匹配的服务器数量。
- 底部“如果没有任何步骤包含可用服务器：{action}”会重复显示**没有服务器符合条件时**的选择。
- 步骤中的标签写作 `tag(name)`。标签名只能包含拉丁字母、数字、`-` 和 `_`，最多 24 个字符，并且必须唯一。

### 标签

每个标签以包含条件的行显示。点按可编辑条件，长按（或右键）可**删除**。点按**添加标签**，输入**标签名称**后会打开条件构建器。

## 工作台中的条件

**使用**、**排除**、标签行和步骤高级条件会打开[条件构建器](routes.md#条件构建器)。国家通过[国家选择器](routes.md#国家选择器)选择。

## 警告和问题

顶部横幅显示第一个错误并禁用保存。**警告**列出不阻止保存的问题；若与文本行有关，会以“Line {line}:”开头。没有警告时该区域不显示。完整列表见[troubleshooting.md](troubleshooting.md#配置和场景检查)。

> [!NOTE]
> **截图 `studio-warnings`** —— 警告区域指出某一步重复了较早条件，并有一个未使用标签。

**将访问的网站**列出配置检查所访问的主机、各主机用途（例如“检查 {name}”），并在适用时标记“第三方”。页脚说明：“第三方网站既不属于你的服务商，也不属于内置配置”。

## 针对组进行检查

至少有一个智能组时显示**检查**区域。**针对组**行提供**无**和现有智能组。选择组后，可查看此配置现在会如何运行，而不会实际应用。结果下方最多列出排名前六的服务器，包含步骤、“检查后可能进入‘{tier}’”或排除原因及延迟；配置会选择的服务器会高亮。

| 结果 | 含义 |
| --- | --- |
| **保持 {pick}** | 该组当前使用的服务器就是配置会选中的服务器。 |
| **改选 {pick}，而非 {now}** | 配置会切换服务器。 |
| **没有可用服务器** | 没有服务器符合条件。 |

> [!NOTE]
> **截图 `studio-check`** —— 针对“Proxy”组的检查显示“改选 🇳🇴 Oslo 1，而非 🇸🇪 Stockholm 1”。

## 合并原配置的更改

如果副本来自内置配置或服务商配置，而原配置后来发生变化，则会显示**原始配置已更改**区域。

| 行 | 功能 |
| --- | --- |
| **合并更改**（“你自己的编辑会保留”） | 将原配置的新变化合并进副本。 |
| **查看更改** | 显示复制时的原配置与新版本之间的逐行差异。 |

可能显示：**更改已合并**；“已合并；你也修改了这些字段，因此保留你的值：{keys}”；或**无法合并更改**。

> [!NOTE]
> **截图 `studio-merge`** —— “原始配置已更改”区域及其两个操作行。

## 历史记录和恢复

右上角菜单包含**早期版本**。配置有历史版本时才显示此项。选择版本会将其放入编辑器；按保存后才会生效。保存配置时，会保留被替换的旧文本；每个配置最多保留 10 个版本。菜单还包含**导出**，已保存的配置另有**删除**（确认提示：“删除‘{profile}’？”）。

> [!NOTE]
> **截图 `studio-restore`** —— 早期版本面板显示时间戳。

## 场景工作台

场景编辑器（参见[hub.md#the-scenario-editor](hub.md#场景编辑器)）包含**YAML**、**导出**，以及已保存场景的**删除**菜单，但没有**早期版本**。其表单对应“路由”选项卡。
