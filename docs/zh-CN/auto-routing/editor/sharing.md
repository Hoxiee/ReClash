# 共享：导出、导入和链接

可以通过文件、文本或链接，将场景或配置发送到另一台设备。

文本格式和配置包详情见：[共享指南](../sharing.md)。

## 导出

打开“库”，长按卡片并选择**导出**；也可以在场景编辑器或工作台菜单中选择**导出**。

> [!NOTE]
> **截图 `export-sheet`** —— 显示三种操作的导出面板。

| 操作 | 结果 |
| --- | --- |
| **导出到剪贴板** | 复制 YAML 文本。 |
| **复制链接** | 复制包含压缩文本的 `reclash://routing?p=…` 链接。提示：“复制成功”。大小限制为 64 KiB。 |
| **导出文件** | 保存为 `<name>.rcx.yaml`。 |

### 普通文档或配置包

- 若项目仅引用内置配置，则只导出该项目本身。
- 若场景引用了你的配置或服务商配置，则会导出一个**配置包**，将场景及其所需的所有配置放入同一个文件，以便在其他设备上使用。

## 导入

打开路由中心的三点菜单，选择**导入**，然后选择**从剪贴板导入**或**从文件导入**。也可以粘贴 `reclash://routing?p=…` 链接，或指向载荷的 HTTPS 链接。

> [!NOTE]
> **截图 `import-page`** —— 单个场景的“导入路由配置”页面，显示标题、来源和说明。

**“导入路由配置”**页面会显示：

| 区域 | 含义 |
| --- | --- |
| **此文件中的项目**列表 | 包含多个项目时，每项显示标题和“场景”或“配置”类型；底部显示来源。 |
| 单个项目 | 标题、级别（配置）或“场景”、来源及说明。 |
| **检查用于 {group}** | 从组面板导入的配置会针对该组进行测试。 |
| **将访问的网站** | 列出目标主机；必要时标记“第三方”。 |
| **警告** | 不会阻止导入的问题。 |
| 提示横幅 | 错误；出现第一个错误时会禁用保存。 |

> [!NOTE]
> **截图 `import-bundle`** —— 配置包导入页面，列出一个场景和两个配置。

点按**添加到我的配置**。提示：“已添加‘{profile}’”。项目会放入**我的**分类；场景不会自动启动。

### 名称冲突时重命名

如果标题已存在，导入器会给新项目添加数字后缀，而不会覆盖现有项目。

### 问题处理

| 消息 | 含义 |
| --- | --- |
| “启动应用内核以检查此配置。” | Core 未运行，因此无法检查文件。请启动连接后重试。 |
| 解析错误横幅 | 文件无效；请参阅[故障排查](troubleshooting.md)。 |
| 授权提示 | 导入项目会连接一些主机；导入后可选择是否允许。 |

> [!NOTE]
> **截图 `import-problems`** —— 导入页面显示错误横幅，并禁用保存操作。

## 操作示例：将设置分享至另一台设备

在已配置“我的分流”的设备上：

1. 打开**自动路由**，进入**库**选项卡并筛选**场景**。
2. 长按**我的分流**，选择**导出**。
3. 选择**复制链接**。屏幕会提示“复制成功”。（如需文件，选择**导出文件**。）
4. 将链接通过消息发送给自己。

在另一台设备上：

1. 在 ReClash 中打开链接；或复制链接后进入**自动路由**，打开三点菜单并选择**导入** → **从剪贴板导入**。
2. 检查页面中的标题、项目以及**将访问的网站**。
3. 点按**添加到我的配置**。
4. 转到**概览**选项卡，点按**更改**并选择**我的分流**。

配置中提到的服务器（⚡ RU、Stockholm）必须存在于另一台设备的订阅中，步骤才能找到它们；配置本身可以跨设备使用。
