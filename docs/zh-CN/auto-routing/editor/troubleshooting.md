# 故障排查

本页列出编辑器显示的消息、原因和处理方法。较新 Core 返回的未知代码会原样显示（例如 `some.code`）；若看到此类代码，请更新 ReClash。

## 状态卡片中的原因

| 消息 | 含义 | 处理方法 |
| --- | --- | --- |
| 手动控制 | 组处于 Manual 模式。 | 选择 **Auto**，让 ReClash 决策。 |
| 保持固定服务器 | 服务器已固定且正常工作。 | 无需处理。 |
| 已切换到固定服务器 {node} | 你固定了服务器。 | 无需处理。 |
| 节点池中没有可用服务器；保留当前服务器 | 池中所有服务器均故障。 | 检查网络；在**更改为**中选择**任意**以扩大节点池。 |
| 没有可用服务器；已回退到 {node} | 行为配置选择了回退服务器。 | 检查服务器。 |
| 已选择最佳可用服务器 | 首次选择。 | 无需处理。 |
| 已更换服务器；{from} 将跳过 15 分钟 | 你点按了**更换服务器**。 | 等待，或再次选择。 |
| {from} 已停止工作；切换到最佳备用节点 | 故障切换。 | 无需处理，可查看历史记录。 |
| {from} 已不在节点池中 | 节点池或订阅发生变化。 | 检查**更改为**和名称模式。 |
| 没有其他可用服务器可切换 | **更换服务器**没有找到替代项。 | 更新订阅。 |
| 当前已是最佳服务器 | 没有更优节点。 | 无需处理。 |
| 正在检查更优候选项 | 检查正在运行。 | 请等待。 |
| 当前服务器可用；保持到故障为止 | 引擎保留可用服务器。 | 将**切换策略**提高为**频繁**，可更早切换。 |
| 最近刚切换；等待后才能再次切换 | 保持时间尚未结束。 | 请等待。 |
| 已达到切换上限（每小时 {limit} 次） | 防止频繁切换机制已生效。 | 请等待或选择 **Pinned**。 |
| 更快的服务器还需要一次测量 | 正在确认结果。 | 请等待。 |
| 已切换到“{tier}”步骤中的服务器 | 优先级更高的步骤中存在可用服务器。 | 无需处理。 |
| 已从 {from} 切换：快了 {gain} ms | 延迟更低。 | 无需处理。 |
| 无法选择服务器 | Core 拒绝了此次选择。 | 确认该组是选择器，然后重新启动连接。 |
| 检查确认后将切换到 {node} | 正在等待更优节点的检查结果。 | 无需处理。 |
| 可能在 {minutes} 分钟后切换到 {node} | 正等待保持时间结束后切换。 | 无需处理。 |
| 如果优势保持在 {gain} ms，将切换到 {node} | 正在等待确认性能优势。 | 无需处理。 |
| 网络可能已断开；不会判定任何服务器故障 | 多台服务器同时失败。 | 检查网络。 |
| 网络已更改 | 网络发生切换，正在重新评估。 | 无需处理。 |
| 网络处于“{kind}”状态时已暂停：不检查、不切换 | 网络类型（例如登录页面）会暂停自动路由。 | 登录网络或更换网络。 |
| 直连网站现在通过此组 / 网站恢复直连 | 直连分流状态发生变化。 | 参见[groups.md](groups.md#设置页面)。 |
| 场景固定到 {node} | 路由设置为单个服务器。 | 无需处理。 |
| 场景切换到 {node} | 已应用固定目标。 | 无需处理。 |
| {node} 不在此组中 | 固定服务器不存在于组内。 | 编辑路由：**流量通过** → **单个服务器** → 重新选择。 |
| 未启用：模式为 {mode} | 当前连接不在 rule 模式下。 | 切换到 rule 模式。 |

## 服务器被排除的原因

| 消息 | 含义 |
| --- | --- |
| 不在节点池中 | 不匹配名称模式、**使用**条件或所选节点池。 |
| 被配置排除 | 匹配了**排除**条件。 |
| 不是服务器 | 是组或内置项目，而非服务器。 |
| 更换服务器后跳过 | 将跳过 15 分钟。 |
| 不符合任何偏好 | 不符合任一步骤，且没有兜底步骤。请添加**任意可用服务器**。 |
| 尚未检查 | 等待首次测量。 |
| 不可用 | 健康状态为故障。 |

## 组和配置问题

| 消息 | 原因 | 处理方法 |
| --- | --- | --- |
| 未找到配置 {profile}；将使用默认配置 | 所选行为已被删除。 | 在**行为**中选择其他配置。 |
| 配置错误：{error} | 配置编译失败。 | 在[工作台](studio.md)中打开并修正。 |
| 当前配置中的组不是选择器 | 组类型已更改。 | 检查订阅。 |
| 组中没有服务器 | 组为空。 | 更新订阅。 |
| 无法保存路由状态：{error} | 磁盘写入失败。 | 清理磁盘空间并重试。 |
| 需要授权 | 配置希望访问网站。 | [允许](groups.md#授权)访问，或选择其他行为。 |

## 路由问题

| 消息 | 原因 | 处理方法 |
| --- | --- | --- |
| 路由名称已占用（`route.name-taken`） | 订阅中的另一个组已使用该路由名。 | 重命名路由。 |
| 路由目标不存在（`route.to-missing`） | “单个服务器”目标已从订阅中移除。 | 选择其他目标。 |
| 路由无效（`route.invalid`） | 路由验证失败。 | 打开路由并修正字段。 |
| 路由仅在 rule 模式下生效；当前连接使用 {mode} 模式。 | 不是 rule 模式。 | 切换到 rule 模式。 |

名称字段错误包括：**必填**、**名称过长**、**该名称已保留**、**{label}已存在**。参见[routes.md](routes.md#名称规则)。

## 配置和场景检查

以**警告**或横幅显示；若关联文本行，会加上“Line {line}:”前缀。

| 消息 | 含义 | 处理方法 |
| --- | --- | --- |
| 检查 {check} 从未使用，因此不会运行 | 声明的检查没有被引用。 | 使用或删除它。 |
| 会访问第三方网站：{hosts} | 需要授权。 | 检查主机；若可信则允许。 |
| 组 {group} 中没有服务器通过筛选 | **使用** / **排除**条件移除了所有服务器。 | 放宽筛选条件。 |
| 标签 {tag} 从未使用 | 标签未被引用。 | 删除它。 |
| 当前组 {group} 在“{tier}”中没有服务器 | 该步骤目前为空。 | 若非预期，请修改条件。 |
| “{tier}”重复了“{after}”的条件，因此没有节点会进入该步骤 | 步骤被前面的条件覆盖。 | 调整顺序或删除步骤。 |
| 配置中没有组 {group} | 场景指定了订阅不存在的组。 | 删除此规则或选择现有组。 |
| 标签名仅能使用拉丁字母、数字、- 和 _，最多 24 个字符 | 标签名无效。 | 重命名。 |
| 仅限小写拉丁字母、数字和连字符，最多 24 个字符 | 网络类型名无效。 | 重命名。 |
| 名称模式不是有效的正则表达式 | 模式无效。 | 修正或清空。 |
| 此条件包含嵌套组，因此使用文本编辑 | 这不是错误。 | 使用**文本形式**。 |
| 值无效 | 条目值不被接受。 | 参见[routes.md](routes.md#验证)。 |

## 其他情况

| 情况 | 处理方法 |
| --- | --- |
| “启动连接以查看自动路由” | 启动连接。 |
| “启动应用内核以检查此配置” | 启动连接。 |
| “无法合并更改” | 原配置无法再合并；通过**查看更改**并手动应用。 |
| 保存按钮呈灰色 | 查看错误横幅；第一个错误会禁用保存。 |
| 链接过大 | 链接最多可携带 64 KiB 文本，请使用**导出文件**。 |
| 导入时项目被重命名 | 名称冲突，参见[sharing.md#renaming-on-a-clash](sharing.md#名称冲突时重命名)。 |
