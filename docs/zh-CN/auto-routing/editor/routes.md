# 路由、服务器顺序与选择器

本页介绍从“路由”选项卡进入的界面：流量选择器、路由编辑器、服务器顺序（阶梯）编辑器、国家选择器和条件构建器。

## 为单个服务添加路由

1. 打开**自动路由** → **路由**选项卡。
2. 点按**添加路由**，页面标题为**新建路由**。
3. 选择路由接管的服务（参见[流量选择器](#流量选择器)）。页脚提示：“选择此路由接管的服务，也可添加自定义条目。”
4. 点按**下一步**；未选择任何内容时按钮不可用。
5. 打开[路由编辑器](#路由编辑器)，名称会根据你选的第一个服务预填。如果名称已被占用，字段会留空，需要自行输入。
6. 设置**流量通过**，可选编辑服务器顺序，然后保存。

ReClash 会创建一个以路由命名的 select 组，将路由加入列表，并重新应用配置一次。该路由会显示在路由中心的“路由”列表以及“代理”页面中。

### 自定义条目

在**自定义**区域（“此路由还接管的域名、IP 范围、应用或规则集”）中点按**添加条目**。条目表单包括：

| 控件 | 说明 |
| --- | --- |
| **类型** | 条目类型菜单，见下表。 |
| **值** | 类型对应的值和输入提示。 |
| **不解析域名** | 仅 IP 类型显示。除非确定需要，否则不要开启。 |

| 类型 | 匹配内容 | 示例 |
| --- | --- | --- |
| **域及其子域** | 域名及所有子域（“域名后缀也会匹配所有子域”）。 | `example.com` |
| **域名** | 仅此主机名。 | `www.example.com` |
| **域名关键字** | 任意包含该字符串的主机名。 | `example` |
| **网站类别** | 按名称匹配网站列表。 | `category-ai-chat-!cn`、`telegram` |
| **IP 类别** | 国家或服务 IP 列表。 | `telegram` |
| **IP 范围** | CIDR 网段；若值中有冒号则识别为 IPv6。 | `10.0.0.0/8` |
| **应用** | 进程名称（桌面端）。 | `Telegram.exe` |
| **规则集** | 配置中的命名规则集。 | `my-rules` |

每行显示值和类型。点按可编辑，长按可**删除**。

### 验证

| 消息 | 原因 |
| --- | --- |
| **必填** | 值为空。 |
| **值无效** | 含逗号或开头空格；域名含非法字符；类别包含字母、数字、`!@._-` 之外的字符；CIDR 不是有效地址和前缀；端口或 AS 编号不是数字。 |

限制：每条路由最多 128 个条目；每个场景最多 32 条路由。

## 路由编辑器

> [!NOTE]
> **截图 `route-editor`** —— “▶️ YouTube”编辑器包含名称、流量摘要“YouTube · 另 2 项”、“流量通过：Auto”、服务器顺序和行为。

页面标题是路由名称或**新建路由**。控件从上到下为：

| 控件 | 功能 |
| --- | --- |
| **名称** | 路由及其组的名称。提示示例 `▶️ YouTube`。 |
| 流量摘要 | 例如“YouTube · 另 2 项”：先显示服务，再显示自定义值。点按可重新打开选择器。 |
| **流量通过** | Auto、单个服务器、直连。 |
| **服务器** | 选择“单个服务器”时显示。 |
| **服务器顺序** | 选择 Auto 时显示，见[下文](#服务器顺序编辑器)。 |
| **行为** | 选择 Auto 时显示。 |
| **排除** | 选择 Auto 时显示（程序还会显示**使用**）。排除该路由的服务器。 |

### 名称规则

| 消息 | 规则 |
| --- | --- |
| **必填** | 必须填写名称。 |
| **名称过长** | UTF-8 最多 64 字节（每个 emoji 占 4 字节）。 |
| **该名称已保留** | 不允许：`$main`、`*`、`GLOBAL`、`DIRECT`、`REJECT`。 |
| **{label}已存在** | 其他路由或订阅组已使用此名称。 |

名称无效、未选择流量，或选择“单个服务器”但未指定服务器时，保存按钮不可用。

### 流量通过

| 选项 | 含义 |
| --- | --- |
| **Auto** | “路由自己的组会按下方顺序选择最佳服务器。” |
| **单个服务器** | “此流量始终通过所选服务器或组。”在**服务器**行选择；列表分为**组**和**服务器**。对“所有组”规则不可用。 |
| **直连** | “此流量绕过代理。”仅适用于普通路由。 |

从 Auto 切换后，该路由的服务器顺序、行为和排除项会被清除。

> [!NOTE]
> **截图 `route-editor-fixed`** —— 路由编辑器选择“单个服务器”，服务器行为显示“🇳🇴 Oslo 1”。

“其他组”中的组规则有另一个固定选项：**交给一个成员**，包含**成员**行。说明：“整个组固定通过该成员，不搜索服务器；选择负载均衡器或嵌套组即可整体转发。”摘要显示“通过 {member}”。

### 行为

点按**行为**，选择此组在服务器顺序中如何挑选服务器。

> [!NOTE]
> **截图 `route-behaviour`** —— 行为页面分为内置、来自服务商、用户，并在页脚显示说明。

- 路由默认使用内置 Simple。
- 组规则的首个选项为**组自身配置**（“该组继续使用自身设置中的行为”）。
- 页脚显示已选行为的说明。

### 使用和排除

这些行会打开[条件构建器](#条件构建器)。**使用**（默认“任意服务器”）缩小组可用服务器范围；**排除**（默认“无”）移除服务器。例如，可排除 `Provider is …` 或 `Latency over …`。

> [!NOTE]
> **截图 `route-pool`** —— 组规则中“排除”行显示“名称包含…”，下方为“使用”行。

### 保存

保存时会检查整个场景。字段错误显示在字段旁，其他错误显示在横幅中。参见[故障排查](troubleshooting.md)。

## 服务器顺序编辑器

服务器顺序（契约中称为“阶梯”）定义服务器优先级。步骤构成优先级列表：先尝试步骤 1，再尝试步骤 2，依次类推。第一个含有可用服务器的步骤获胜。无论属于哪个步骤，不可用服务器都会排在所有可用服务器之后。

> [!NOTE]
> **截图 `route-editor-ladder`** —— 服务器顺序中有“⚡ RU”和“任意可用服务器”两个步骤，通过“如果都不可用”连接，并提供添加步骤按钮。

### 列表

**服务器顺序**标题栏有两个按钮：排序开关（至少两个步骤时显示）和**添加步骤**。

| 部分 | 含义 |
| --- | --- |
| 数字标记 | 步骤位置。当前服务器属于此步骤时会高亮（仅组面板）。 |
| 标题 | 标签或条件摘要。 |
| 副标题 | 条件；启用时附有“最后回退”。 |
| 右侧“N 台服务器” | 当前匹配服务器数；为零时显示红色。仅组面板显示。 |
| 步骤间说明 | 第一个连接说明为“如果都不可用”。 |
| 空列表 | 显示**任意可用服务器**及提示“添加步骤以优先选择某些服务器”。 |

长按步骤可**删除**。通过排序开关重新排列。若路由没有自己的步骤，则会以弱化样式显示行为配置中的步骤，并提示“来自行为——编辑步骤以设置自己的顺序”。首次编辑时会先复制到路由中。

若配置了“没有步骤匹配时”的行为，底部会显示“若没有任何步骤包含可用服务器：{action}”，选项为**直连**或**保留当前服务器**。

### 步骤编辑器

点按**添加步骤**或现有步骤。标题为**添加步骤**或**步骤 {number}**；编辑已有步骤时会显示删除图标。

> [!NOTE]
> **截图 `ladder-step-editor`** —— 步骤编辑器的名称包含“⚡ RU”、国家行、添加条件，以及“当前匹配 2 台服务器”的页脚。

**此步骤中的服务器**区域：

| 行 | 含义 |
| --- | --- |
| **名称包含** | 服务器名称中的文本，不区分大小写。`*` 和 `.` 等字符按字面匹配。摘要为“名称中含 {text}”。 |
| **国家** | 打开[国家选择器](#国家选择器)。副标题为“任意”或国家名（超过两个国家时只显示旗帜）。 |
| **除以下国家外** | 选好国家后显示的开关，摘要为“不是 {what}”。 |
| **服务商** | 来自某个服务商的服务器（“来自 {provider}”），选项来自当前服务器。 |
| **协议** | 服务器类型，例如 vless。 |
| **标签** | 命名的服务器集合；仅当场景或配置声明标签时显示（“标签 {tag}”）。 |
| **支持 UDP** | 只选支持 UDP 的服务器（“UDP”）。 |
| **延迟低于（ms）** | 默认 300（摘要“低于 {ms} ms”），仅接受数字。 |
| **其他条件** | 快速构建器无法显示的条件；点按后以文本编辑。 |
| **添加条件** | 显示以上附加行和**高级条件…**菜单。 |

添加的行会有删除按钮。所有条件必须同时成立（通过“and”连接）。

页脚会根据当前服务器显示“当前匹配 {count} 台服务器”。无法在本地检查的条件不显示此页脚。

第二部分为**标签**（提示内容是条件摘要）和**最后回退**。说明：“最后回退步骤中的服务器，仅当其他步骤都没有可用服务器时才会使用，即使其他步骤排在其后也一样”。

### 示例：YouTube 优先使用 ⚡ RU，之后任意服务器

1. 步骤 1：**名称包含** `⚡ RU`。页脚显示当前匹配 2 台服务器。
2. 步骤 2：不设置条件，显示为**任意可用服务器**。

只要莫斯科 ⚡ 1 和 2 可用，就会使用它们；两者都故障后，改用其他任意可用服务器。如果反转顺序，第一个步骤会匹配所有服务器。

### 示例：Claude 优先选择瑞典

一个步骤将**国家**设为瑞典（🇸🇪 Stockholm 1 和 2）。如果需要回退，可添加第二步**任意可用服务器**；否则瑞典服务器都不可用时，组将没有优先服务器。

### 最后回退步骤

对仅希望在其他服务器都不可用时使用的服务器（例如 Premium NL），添加一个开启**最后回退**的步骤。它可以放在列表任意位置，但始终最后应用。

## 国家选择器

> [!NOTE]
> **截图 `country-picker`** —— 国家选择面板显示“你的服务器”分区：挪威 3 台（已验证）、瑞典 2 台、俄罗斯 2 台，以及全部国家。

选择器是带搜索框的面板。多选时标题为**选择国家**；单选时为**选择一个国家**（点按后立即选择并关闭）。

| 分区 | 内容 |
| --- | --- |
| **你的服务器** | 服务器中找到的国家、对应服务器数量，以及出口国家经检查验证后的“已验证”标记。 |
| **所有国家** | 按字母顺序排列的完整国家列表。 |

搜索可匹配 ISO 代码、英文名或俄文名。所选行带有勾选标记；多选时点按顶部栏的勾选图标确认。

服务器国家优先采用已验证的出口国家；否则按名称依次判断：国旗 emoji、独立的大写两位 ISO 代码、英文国家名。没有国家信息的服务器不会匹配国家条件，也不会只为识别国家而触发检查。

## 条件构建器

可从**使用**、**排除**、**高级条件…**、其他条件、标签，以及网络类型的**识别条件**打开。

> [!NOTE]
> **截图 `condition-builder`** —— 构建器设置“匹配全部条件”，条件为国家属于挪威或瑞典，且延迟低于 300。

### 表单模式

| 控件 | 说明 |
| --- | --- |
| **匹配** | **所有条件**或**任一条件**；至少两项时显示。 |
| **条件 {number}** | 每个子句一个区域，带删除按钮。 |
| **字段** | 见下表。 |
| **运算符** | **是**、**不是**、**属于其中之一**、**匹配**、**检查通过**、**检查失败**、**低于**、**不高于**、**高于**、**不低于**，并可使用否定形式。真假字段使用是/否。 |
| **值** / **逗号分隔的值** / **模式** | 取决于字段和运算符。 |
| **忽略大小写** | 用于**匹配**（正则表达式）。 |
| **添加条件** | 新增子句。 |

| 字段 | 含义 |
| --- | --- |
| 名称 | 服务器名称。 |
| 国家 | 已验证的出口国家，或从名称读取的国家。 |
| 服务商、协议、服务器地址 | 服务器来源和信息。 |
| 支持 UDP | 服务器支持 UDP。 |
| 可用、不可用 | 服务器健康状态。 |
| 已测量 | 服务器是否有延迟数据。 |
| 正在使用 | 组当前是否使用该服务器。 |
| 延迟（ms） | 最近一次延迟。 |
| 出口国家、入口国家 | 通过检查获取的国家。 |
| 网络类型、连接类型、登录页面、按流量计费的网络 | 网络条件。 |
| 标签 | 是否属于某个标签。 |
| 检查通过、检查失败、网络诊断 | 配置中声明的检查结果。 |

国家字段使用**属于其中之一**时，值行会打开国家选择器；使用**是**时只能选择一个国家。

空白构建器显示**任意服务器**（网络条件则显示**始终**）。

### 文本模式

**文本形式**区域会显示并实时编辑条件文本（停止输入约 0.4 秒后检查）。解析错误会显示横幅并禁用保存。若条件包含嵌套组，则会提示“此条件包含嵌套组，因此使用文本编辑”。语法见[conditions.md](../conditions.md)。

> [!NOTE]
> **截图 `condition-text`** —— “文本形式”区域显示解析错误横幅。
