# 自动路由编辑器指南

自动路由（内部名称 RCX）可让 ReClash 自动选择服务器，并将指定流量（例如某个服务的流量）通过指定服务器转发。本节介绍所有设置界面，仅涵盖编辑器本身。相同设置的文本格式、引擎规则和示例集请参阅本页末尾的链接。

> [!NOTE]
> **截图 `editor-map`** —— 并排展示三个入口：路由中心（“概览”选项卡）、从“代理”页打开的组面板，以及路由编辑器；箭头标注了从一个入口到另一个入口的路径。

## 术语

| 术语 | 含义 |
| --- | --- |
| 场景 | 以单个文件保存的完整设置，包括路由、组规则和按网络变化的配置。一次只能运行一个场景。 |
| 路由 | 场景中的一条规则：“这类流量通过这些服务器”。路由有顺序，流量采用第一个匹配项。 |
| 组 | 订阅中的 `select` 组（例如主代理组）。每条路由也会创建一个以路由命名的组。 |
| 行为 | 组配置，即智能组选择服务器的方式（Simple、Fastest、Stable、Bypass 等）。 |
| 服务器顺序 | 有序步骤列表。第一个包含可用服务器的步骤获胜。 |
| 步骤 | 服务器顺序中的一行：例如“国家为瑞典”的条件，以及可选标签。 |
| 控制方式 | 由谁决定组的服务器：Auto、固定或手动。 |

## 各功能入口

| 功能 | 打开方式 |
| --- | --- |
| 自动路由中心（概览、路由、库选项卡） | 高级设置 → **自动路由** |
| 组面板（状态、控制、行为、历史记录） | “代理” → 点按一个组 → 点按组的自动路由按钮 |
| 路由编辑器 | 路由中心 → **路由**选项卡 → 点按路由或**添加路由** |
| 场景编辑器 | 路由中心 → **库**选项卡 → 点按场景 |
| 组配置工作台 | 路由中心 → **库**选项卡 → **组配置**筛选器 → 点按配置；也可点按组的行为行 |
| 导入 | 路由中心 → 三点菜单 → **导入** |
| 导出 | 场景或配置菜单，或在库中长按卡片 |

> [!NOTE]
> 可从“高级设置”→“自动路由”打开路由中心，也可从“代理”中的组面板进入。

## 各部分如何配合

1. **场景**是当前运行的设置，可在路由中心启用。
2. 场景中包含**路由**。每条路由接管部分流量（服务、域名、IP 范围、应用），并将其发送到专属组、固定服务器或直连。
3. 路由创建的组通过**行为**和**服务器顺序**来选择服务器。
4. 场景未指定的组会继续作为**智能组**运行，并使用在组面板中设置的自身行为。
5. 所有更改会一起保存。路由更改会在最后一次编辑后稍作等待，然后重新应用配置一次。

路由仅在 `rule` 模式下工作。在 `global` 或 `direct` 模式下，“路由”选项卡会说明当前情况，路由不会生效。
