# Сценарии

Справочник формата сценария RCX: программы для групп, маршруты, типы сетей и режим туннеля.

## Документ

Сценарий — одно отображение YAML размером не больше 64 КиБ; неизвестные ключи отвергаются. На подписку работает один
сценарий: выбор пользователя, иначе `rcx-scenario` подписки. Выключение автомаршрутизации сохраняет выбор, но останавливает
сценарий.

```yaml title="split.rcx.yaml"
rcx: 1
title: My split
mode: rule
tags:
  fast-ru: "name ~ '⚡ RU'"
groups:
  $main: { profile: builtin/fastest, prefer: [{ label: Norway, when: 'country = NO' }] }
  '*': {}
routes:
  - name: YouTube
    match: [GEOSITE,youtube]
    prefer:
      - { label: Fast RU, when: 'tag(fast-ru)' }
      - { label: Any, when: 'not dead' }
  - name: Claude
    match: [GEOSITE,anthropic]
    prefer: [{ label: Sweden, when: 'country = SE' }]
  - name: Local
    match: ['GEOSITE,category-ru', 'DOMAIN-SUFFIX,yandex.ru']
    to: DIRECT
```

| Ключ | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `rcx` | целое | 1 | Версия формата; больше 1 отвергается. |
| `title`, `description` | строка | — | Отображаемый текст. |
| `tags` | имя → серверное условие | — | Видны каждой программе, вдобавок к тегам её профиля. |
| `network` | `{diagnose, kinds}` | — | Как в профиле; см. [Сеть](profiles.md#network). |
| `mode` | `rule` \| `global` \| `direct` | — | Режим туннеля, который держит сценарий; пусто — режим задаёт пользователь. |
| `groups` | цель → программа | — | Программы по группам; см. [Цели](#targets). Не больше 32. |
| `routes` | список маршрутов | — | Правила перед правилами конфига; см. [Маршруты](#routes). |
| `on` | тип → `{mode, groups}` | — | Изменения в одном типе сети. |
| `l10n` | переводы | — | Как в профиле. |

## Программы

| Ключ | Тип | Описание |
| --- | --- | --- |
| `profile` | id профиля | Заменяет профиль группы. Иначе группа сохраняет профиль своей привязки, а без неё — `builtin/simple`. |
| `pool` | `{include, exclude}` | Сужает пул привязки ещё больше. |
| `prefer` | список уровней, не больше 16 | Заменяет порядок серверов; важнее порядка привязки пользователя. |
| `to` | имя элемента | Держит группу на одном элементе (сервер, балансировщик, вложенная группа) без поиска. Исключает остальные ключи. |

`to` вместе с любым другим ключом даёт ошибку `to holds one member, so profile, pool and prefer do not apply`.
Программа с `pool` или `prefer` без `profile` проверяется при запуске — против собственного профиля группы.

## Цели

| Ключ | К чему применяется |
| --- | --- |
| Имя группы | К этой группе. 1–64 символа. |
| Имя маршрута | Нельзя: маршрут несёт свою программу. |
| `$main` | Группа, на которую ведёт последнее правило `MATCH`. |
| `*` | Каждая другая группа-селектор, кроме `GLOBAL`. |

Приоритет для одной группы: точное имя, программа её маршрута, `$main`, затем `*`. Группа, которую сценарий не называет,
сохраняет свою привязку или остаётся обычным селектором.

## Маршруты

```yaml
# fragment
routes:
  - name: Work
    description: Office services through the Netherlands
    match:
      - DOMAIN-SUFFIX,corp.example
      - IP-CIDR,10.20.0.0/16,no-resolve
      - PROCESS-NAME,teams.exe
    pool: { include: 'country = NL' }
```

| Ключ | Тип | Описание |
| --- | --- | --- |
| `name` | строка | 1–64 байта, без пробелов по краям, без запятых и управляющих символов, уникальное. Становится именем группы. |
| `description` | строка | Не больше 240 байт. |
| `match` | список `TYPE,value[,no-resolve]` | 1–128 записей. |
| `profile`, `pool`, `prefer` | ключи программы | Как выбирает собственная группа маршрута. |
| `to` | цель | Отправлять совпадения в существующий прокси, группу, встроенную цель или группу другого маршрута вместо создания группы. |

Зарезервированные имена: `$main`, `*`, `GLOBAL`, `DIRECT`, `REJECT`, `REJECT-DROP`, `PASS`, `COMPATIBLE`.

### Типы совпадений

| Тип | Значение | `no-resolve` |
| --- | --- | --- |
| `DOMAIN`, `DOMAIN-SUFFIX`, `DOMAIN-KEYWORD`, `DOMAIN-WILDCARD` | Текст домена | Нет |
| `DOMAIN-REGEX` | Регулярное выражение; весь остаток записи | Нет |
| `GEOSITE` | Категория сайтов | Нет |
| `GEOIP` | Код страны или категории | Да |
| `IP-CIDR`, `IP-CIDR6` | Диапазон адресов | Да |
| `IP-ASN` | Номер AS | Да |
| `SRC-IP-CIDR` | Диапазон адресов источника | Нет |
| `DST-PORT` | Порты или диапазоны через `/`: `443/8000-8100` | Нет |
| `PROCESS-NAME`, `PROCESS-PATH` | Имя или путь процесса | Нет |
| `RULE-SET` | Имя провайдера правил в конфиге | Да |

Типы не зависят от регистра. Список YAML в потоковой записи, например `[GEOSITE,youtube]`, читается как одна запись:
элемент-тип объединяется со следующим элементом и необязательным `no-resolve`.

### Применение

Маршруты вступают в силу только при применении конфига. Каждый маршрут без `to` добавляет группу-селектор с
`include-all: true` и правилами маршрута — в порядке маршрутов, перед всеми правилами конфига. Изменение имени, совпадений
или `to` маршрута запрашивает одно повторное применение, которое выполняет приложение; изменение программы применяется на
лету.

| Проблема | Код | Причина |
| --- | --- | --- |
| Имя занято | `route.name-taken` | Маршрут без `to` назван как существующий прокси, группа или встроенная цель. |
| Нет цели | `route.to-missing` | `to` не называет ничего в конфиге или маршрутах. |
| Неверный | `route.invalid` | `RULE-SET` нет в конфиге, или mihomo отверг правило или группу маршрута. |
| Не режим правил | `route.not-rule-mode` | Маршруты есть, но режим туннеля не `rule`. |

Отвергнутый маршрут отбрасывается, и конфиг разбирается заново без него. Сбой, не относящийся к одному маршруту, помечает
неверными все маршруты, и конфиг применяется без них.

## Типы сетей

```yaml
# fragment
network:
  diagnose:
    home: { tcp: ['77.88.8.8:443'] }
    foreign: { tls: ['1.1.1.1:443'] }
  kinds:
    - { kind: whitelist, when: 'home ok and foreign fail' }
on:
  whitelist:
    mode: global
    groups:
      GLOBAL: { profile: builtin/simple, pool: { include: tag(bypass) } }
```

`on.<kind>.groups` заменяет базовую программу по каждому ключу цели; цели, которых он не называет, сохраняют базовую
программу. Без `on.<kind>.mode` действует базовый `mode`. Тип под `on` должен быть объявлен, иначе загрузка падает с
`the scenario declares no network kind <kind>`. Распознавание — см. [Типы сетей](engine.md#network-kinds).

## Режим

Действующий режим туннеля — режим сценария в текущем типе сети, если пользователь не выбрал режим вручную; тогда — режим
пользователя, а без него `rule`. Выбор сценария возвращает режим ему. Группы, через которые в текущем режиме не идёт
трафик, простаивают (`hold.idle`): для них не принимаются решения и не идут проверки.

| Режим | Простаивают |
| --- | --- |
| `rule` | `GLOBAL` |
| `global` | Все группы, кроме `GLOBAL` |
| `direct` | Все группы |

## Лимиты

| Что | Лимит |
| --- | --- |
| Документ | 64 КиБ |
| Программ в `groups` или `on.<kind>.groups` | 32 |
| Имя цели | 1–64 символа |
| Теги | 32; тег не может использовать `tag()` |
| Типы, записи `on` | по 8 |
| Маршруты | 32 |
| Имя и описание маршрута | 64 байта, 240 байт |
| Записей `match` в маршруте | 128 |
