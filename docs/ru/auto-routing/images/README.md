# Снимки экрана

Места для снимков на страницах редактора в приложении и настройка для их съёмки.

## Демонстрационная настройка

- Подписка «Demo» с серверами 🇳🇴 Oslo 1, 🇳🇴 Oslo 2, 🇳🇴 Oslo 3, 🇸🇪 Stockholm 1, 🇸🇪 Stockholm 2, 🇷🇺 Moscow ⚡ 1,
  🇷🇺 Moscow ⚡ 2, *Premium NL, 🇩🇪 Frankfurt.
- Пользовательский сценарий «My split» запущен:
  - «Остальной трафик»: шаг «Страна: Норвегия»;
  - ▶️ YouTube: шаги «Название содержит: ⚡ RU», затем «Любой рабочий сервер»;
  - 🤖 Claude: шаг «Страна: Швеция»;
  - ✨ Gemini: шаг «Название содержит: `*`»;
  - 🏠 Local: «Напрямую»; «Категория сайтов» `category-ru` и «Домен и поддомены» `yandex.ru`.
- Режим rule, светлая тема, 412x915, если в строке не указано иное.
- В библиотеке встроенные поведения и одно пользовательское.
