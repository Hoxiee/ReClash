# Студия

Редактор поведения (профиля): форма и YAML, живой предпросмотр на группе, предупреждения, слияние и прежние версии.

## Открытие

Центр → **Библиотека** → **Поведения**: карточка собственного поведения открывается на месте, любая другая — копией. **Новое поведение** начинается с шаблона с одним уровнем `Working` (`not dead`), `rank.tolerance` 50 и `feel: calm`. Сохранение недоступно, пока есть ошибки или нет изменений. Формат описан в разделе [Профили](../profiles.md).

## Форма

| Раздел | Строки | Ключ |
| --- | --- | --- |
| Шапка | **Название**, описание | `title`, `description` |
| **Что выберет сейчас** | **На группе**: вердикт и лидирующие кандидаты; **Все кандидаты** открывает полное ранжирование | — |
| **Порядок серверов** | Шаги, как в [редакторе маршрута](routes.md#server-order) | `prefer` |
| **Серверы** | **Только серверы**, **Исключить серверы** | `pool` |
| **Характер** | **Переключения**, **Проверки**, **Если сервер не подходит** (**Оставить текущий**, **Идти напрямую**) | `switch.feel`, `energy`, `stranded` |
| **Ещё** | **Основан на**, **Уровень**, **Теги**, **Дополнительно** | `extends`, `level`, `tags` |
| **Обращения к сайтам** | Каждый узел с назначением (проверка, диагностика сети, проверка страны выхода) и пометкой **сторонний** | — |
| **Предупреждения** | Неблокирующие замечания | — |

**Дополнительно** перечисляет части, которые форма не правит; каждая открывает YAML: **Проверки доступности**, **Типы сетей**, **Изменения по сетям**, **Прямые сайты через эту группу**, **Проверка страны выхода**, **Переводы**.

Вердикт предпросмотра — **Оставит {pick}**, **Выберет {pick} вместо {now}** или **Не найдёт сервер**. Предпросмотр ничего не применяет.

> [!NOTE]
> **Снимок экрана `studio-form`** — название, предпросмотр, «Порядок серверов», «Серверы» и «Характер»

> [!NOTE]
> **Снимок экрана `studio-check`** — «Выберет «🇳🇴 Oslo 1» вместо «🇸🇪 Stockholm 1»»

## YAML

**YAML** в меню открывает весь документ текстом; сохранение текста заменяет форму. Правка в форме переписывает текст из разобранного документа, поэтому комментарии теряются. В меню также есть **Экспорт** и, для сохранённого поведения, **Удалить**.

> [!NOTE]
> **Снимок экрана `studio-yaml`** — редактор YAML поведения

## Предупреждения

Первая ошибка показывается в баннере и блокирует сохранение; замечание, привязанное к тексту, начинается со «Строка {line}:».

| Предупреждение | Смысл |
| --- | --- |
| Тег {tag} нигде не используется | Ни одно условие не ссылается на тег. |
| Проверка {check} нигде не используется, поэтому не выполняется | Ни одно условие не ссылается на проверку. |
| «{tier}» повторяет условие «{after}», поэтому в него ничего не попадает | Более поздний уровень недостижим. |
| Ни один сервер группы {group} не проходит фильтр | Пул убирает все серверы группы предпросмотра. |
| Сейчас ни один сервер группы {group} не входит в «{tier}» | Уровень пуст на группе предпросмотра. |
| В этом конфиге нет группы {group} | Сценарий называет отсутствующую группу. |
| Обращается к сторонним сайтам: {hosts} | Записи провайдера нужно согласие; см. [Согласие](../sharing.md#consent). |

> [!NOTE]
> **Снимок экрана `studio-warnings`** — повторённый уровень и неиспользуемый тег

## Слияние

Копия помнит свой оригинал. Когда оригинал меняется, **Оригинал изменился** предлагает **Перенести изменения** (слить изменения оригинала, сохранив собственные правки пользователя) и **Что изменилось** (построчное сравнение). Результат: «Изменения перенесены», «Перенесено; вы тоже меняли это, поэтому сохранены ваши значения: {keys}» или «Не удалось перенести изменения».

> [!NOTE]
> **Снимок экрана `studio-merge`** — «Оригинал изменился» с «Перенести изменения» и «Что изменилось»

## Версии

Каждое сохранение оставляет заменённый текст; для каждого поведения хранятся последние 10 версий. **Прежние версии** в меню загружают одну из них в редактор; сохраняется она при следующем сохранении. Сценарии тоже хранят версии, но редактор их не предлагает.

> [!NOTE]
> **Снимок экрана `studio-restore`** — «Прежние версии» с отметками времени
