# Редактор автоматической маршрутизации

Автоматическая маршрутизация (внутреннее название RCX) позволяет ReClash выбирать серверы и направлять выбранный трафик, например трафик одного сервиса, через заданные серверы. В этом разделе описаны все экраны настройки. Здесь рассматривается только редактор. Текстовый формат тех же настроек, правила движка и примеры приведены на страницах внизу.

> [!NOTE]
> **Снимок экрана `editor-map`** — рядом показаны три точки входа: центр маршрутизации (вкладка «Обзор»), лист группы, открытый со страницы «Прокси», и редактор маршрута; стрелки с подписями показывают переходы между ними.

## Термины

| Термин | Значение |
| --- | --- |
| Сценарий | Вся настройка в одном файле: маршруты, правила групп и изменения для разных сетей. Одновременно работает только один сценарий. |
| Маршрут | Правило сценария: «этот трафик проходит через эти серверы». Маршруты упорядочены; трафик использует первый совпавший. |
| Группа | Группа `select` из подписки (например, основная proxy-группа). Для каждого маршрута также создаётся собственная группа с его именем. |
| Поведение | Профиль группы — способ, которым умная группа выбирает сервер (Simple, Fastest, Stable, Bypass и другие). |
| Порядок серверов | Упорядоченный список шагов. Побеждает первый шаг с работающим сервером. |
| Шаг | Одна строка порядка серверов: условие, например «Страна — Швеция», и необязательная метка. |
| Управление | Кто выбирает сервер группы: Auto, Закреплено или Вручную. |

## Где найти каждый раздел

| Раздел | Как открыть |
| --- | --- |
| Центр маршрутизации (вкладки «Обзор», «Маршруты», «Библиотека») | Дополнительные настройки → **Автоматическая маршрутизация** |
| Лист группы (состояние, управление, поведение, история) | «Прокси» → нажать группу → кнопка авто-маршрутизации группы |
| Редактор маршрута | Центр маршрутизации → вкладка **Маршруты** → выбрать маршрут или **Добавить маршрут** |
| Редактор сценария | Центр маршрутизации → вкладка **Библиотека** → выбрать сценарий |
| Студия профиля группы | Центр маршрутизации → **Библиотека** → фильтр **Профили групп** → выбрать профиль; либо строка поведения группы |
| Импорт | Центр маршрутизации → меню с тремя точками → **Импорт** |
| Экспорт | Меню сценария или профиля либо долгое нажатие на карточку в библиотеке |

> [!NOTE]
> Центр маршрутизации открывается через «Дополнительные настройки» → «Автоматическая маршрутизация» или из листа группы на странице «Прокси».

## Как связаны компоненты

1. **Сценарий** — текущая настройка; его включают в центре маршрутизации.
2. В сценарии находятся **маршруты**. Каждый забирает часть трафика (сервисы, домены, диапазоны IP, приложения) и направляет его в отдельную группу, на фиксированный сервер или напрямую.
3. Собственная группа маршрута выбирает серверы с помощью **поведения** и **порядка серверов**.
4. Группы, не упомянутые в сценарии, продолжают работать как **умные группы** со своим поведением, которое задаётся в листе группы.
5. Все изменения сохраняются вместе. После изменения маршрута профиль применяется один раз, вскоре после последней правки.

Маршруты работают только в режиме `rule`. В режимах `global` и `direct` вкладка «Маршруты» сообщает об этом, а маршруты не применяются.
