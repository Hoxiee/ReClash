# Устранение неполадок

Здесь собраны сообщения редактора, их причины и действия. Неизвестные коды из более нового Core показываются как есть (например, `some.code`); обновите ReClash, если увидели такой код.

## Причины на карточке состояния

| Сообщение | Значение | Что делать |
| --- | --- | --- |
| Управление вручную | Группа в режиме Manual. | Выберите **Auto**, чтобы решение принимал ReClash. |
| Удерживается закреплённый сервер | Сервер закреплён и работает. | Ничего. |
| Переключено на закреплённый сервер {node} | Вы закрепили сервер. | Ничего. |
| В пуле нет работающих серверов; текущий сервер оставлен | Все серверы пула не работают. | Проверьте сеть; расширьте пул через **Изменить на** → **Любой**. |
| Работающих серверов нет; использован резерв {node} | Поведение выбрало резерв. | Проверьте серверы. |
| Выбран лучший доступный сервер | Первый выбор. | Ничего. |
| Сервер изменён; {from} пропущен на 15 минут | Вы нажали **Сменить сервер**. | Подождите или выберите ещё раз. |
| {from} перестал работать; выбрана лучшая запасная группа | Аварийное переключение. | Ничего; см. историю. |
| {from} больше не входит в пул | Изменился пул или подписка. | Проверьте **Изменить на** и шаблон имени. |
| Нет другого работающего сервера для переключения | **Сменить сервер** не нашёл замену. | Обновите подписку. |
| Это лучший сервер | Вариантов лучше нет. | Ничего. |
| Проверяется более подходящий кандидат | Выполняется проверка. | Подождите. |
| Работает; оставлен до отказа | Работающий сервер сохраняется. | Выберите **Часто** в настройке **Переключение**, чтобы переключаться раньше. |
| Недавно переключались; ожидание следующего переключения | Не прошло время выдержки. | Подождите. |
| Достигнут лимит переключений ({limit} в час) | Защита от частых переключений. | Подождите или выберите **Pinned**. |
| Для подтверждения более быстрого сервера требуется ещё одно измерение | Идёт подтверждение. | Подождите. |
| Переключено на сервер шага «{tier}» | В шаге с более высоким приоритетом есть сервер. | Ничего. |
| Переключено с {from}: быстрее на {gain} мс | Выигрыш по задержке. | Ничего. |
| Не удалось выбрать сервер | Core отклонил выбор. | Убедитесь, что группа является селектором; перезапустите подключение. |
| Переключится на {node}, когда проверка подтвердит | Ожидается подтверждение улучшения. | Ничего. |
| Возможно переключение на {node} через {minutes} мин | Ожидается окончание выдержки перед переключением. | Ничего. |
| Переключится на {node}, если преимущество останется {gain} мс | Ожидается подтверждение улучшения. | Ничего. |
| Похоже, сеть не работает; серверы не обвиняются | Одновременно не работают несколько серверов. | Проверьте сеть. |
| Сеть изменилась | Смена сети; выполняется повторная оценка. | Ничего. |
| Пауза в сети «{kind}»: проверки и переключения не выполняются | Тип сети (например, страница входа) приостанавливает авто-маршрутизацию. | Войдите в сеть или смените её. |
| Прямые сайты теперь идут через группу / Сайты снова идут напрямую | Изменилось состояние разделения прямого трафика. | См. [groups.md](groups.md#страница-настроек). |
| Сценарий закрепляет {node} | В маршруте выбрано «Один сервер». | Ничего. |
| Сценарий переключается на {node} | Применена фиксированная цель. | Ничего. |
| {node} отсутствует в этой группе | Фиксированного сервера нет в группе. | Измените маршрут: **Направлять через** → **Один сервер** → выберите сервер снова. |
| Не используется: режим {mode} | Подключение работает не в режиме rule. | Выберите режим rule. |

## Почему сервер исключён

| Сообщение | Значение |
| --- | --- |
| Не в пуле | Не соответствует шаблону имени, **Использовать** или выбранному пулу. |
| Исключён профилем | Соответствует условию **Исключить**. |
| Не сервер | Это группа или встроенный элемент, а не сервер. |
| Пропущен после «Сменить сервер» | Исключён на 15 минут. |
| Не соответствует предпочтениям | Не подходит ни под один шаг и нет общего резервного шага. Добавьте **Любой работающий сервер**. |
| Ещё не проверен | Ожидает первого измерения. |
| Не работает | Состояние: сбои. |

## Проблемы групп и профилей

| Сообщение | Причина | Что делать |
| --- | --- | --- |
| Профиль {profile} не найден; используется профиль по умолчанию | Выбранное поведение удалено. | Выберите другой профиль в разделе **Поведение**. |
| Ошибка профиля: {error} | Не удалось скомпилировать профиль. | Откройте [студию](studio.md) и исправьте ошибку. |
| Текущая конфигурация не содержит группу-селектор | Изменился тип группы. | Проверьте подписку. |
| В группе нет серверов | Группа пуста. | Обновите подписку. |
| Не удалось сохранить состояние маршрутизации: {error} | Ошибка записи на диск. | Освободите место и повторите попытку. |
| Требуется разрешение | Профиль хочет обращаться к сайтам. | [Разрешите](groups.md#согласие) доступ или выберите другое поведение. |

## Проблемы маршрутов

| Сообщение | Причина | Что делать |
| --- | --- | --- |
| Имя маршрута занято (`route.name-taken`) | В подписке уже есть группа с именем маршрута. | Переименуйте маршрут. |
| Цель маршрута отсутствует (`route.to-missing`) | Цель «Один сервер» удалена из подписки. | Выберите другую цель. |
| Недопустимый маршрут (`route.invalid`) | Проверка маршрута не пройдена. | Откройте маршрут и исправьте поле. |
| Маршруты работают в режиме rule; сейчас подключение использует режим {mode}. | Выбран не режим rule. | Переключитесь в режим rule. |

Ошибки имени: **Обязательное поле**, **Имя слишком длинное**, **Это имя зарезервировано**, **{label} уже существует**. См. [routes.md](routes.md#правила-имени).

## Проверки профиля и сценария

Сообщения отображаются в **Предупреждениях** или баннерах; если они относятся к тексту, перед ними указано «Line {line}:».

| Сообщение | Значение | Что делать |
| --- | --- | --- |
| Проверка {check} нигде не используется и не будет выполняться | Объявленная проверка не используется. | Используйте или удалите её. |
| Обращается к сторонним сайтам: {hosts} | Требуется согласие. | Проверьте узлы и разрешите их, если доверяете им. |
| Ни один сервер группы {group} не проходит фильтр | **Использовать** / **Исключить** удаляет все серверы. | Ослабьте фильтры. |
| Метка {tag} не используется | Неиспользуемая метка. | Удалите её. |
| Сейчас нет серверов группы {group} в шаге «{tier}» | Сейчас шаг пуст. | Если это не задумано, измените условие. |
| «{tier}» повторяет условие шага «{after}», поэтому в него ничего не попадает | Шаг перекрыт предыдущим. | Измените порядок или удалите его. |
| В конфигурации нет группы {group} | Сценарий ссылается на группу, отсутствующую в подписке. | Удалите правило или выберите существующую группу. |
| Имя метки: только латинские буквы, цифры, - и _, не более 24 символов | Некорректное имя метки. | Переименуйте. |
| Только строчные латинские буквы, цифры и дефисы, не более 24 | Некорректное имя типа сети. | Переименуйте. |
| Шаблон не является корректным регулярным выражением | Ошибка в шаблоне имени. | Исправьте или очистите поле. |
| Условие содержит вложенные группы, поэтому редактируется как текст | Это не ошибка. | Используйте раздел **Как текст**. |
| Недопустимое значение | Значение записи отклонено. | См. [routes.md](routes.md#проверка-значений). |

## Другие ситуации

| Ситуация | Что делать |
| --- | --- |
| «Запустите подключение, чтобы увидеть авто-маршрутизацию» | Запустите подключение. |
| «Запустите ядро приложения, чтобы проверить этот профиль» | Запустите подключение. |
| «Не удалось перенести изменения» | Оригинал больше не объединяется; посмотрите **Что изменилось** и внесите изменения вручную. |
| Кнопка сохранения неактивна | Проверьте баннер; первая ошибка отключает сохранение. |
| Слишком большая ссылка | Ссылки содержат до 64 КиБ текста; используйте **Экспортировать файл**. |
| При импорте элемент переименован | Совпало имя; см. [sharing.md#renaming-on-a-clash](sharing.md#переименование-при-совпадении-имён). |
