# Редактор маршрута

Редактор маршрута и его средства выбора: трафик, порядок серверов, шаги, страны и условия.

## Трафик

**Добавить маршрут** открывает **Новый маршрут**. **Далее** недоступно, пока не выбран трафик; затем открывается редактор с именем первого сервиса, если оно не занято.

| Часть | Содержимое |
| --- | --- |
| **Сервисы** | Чипы 19 сервисов, у каждого одно или несколько правил: YouTube (`GEOSITE,youtube`), Google, Gemini (`GEOSITE,google-gemini`), ChatGPT (`GEOSITE,openai`), Claude (`GEOSITE,anthropic`), Telegram (ещё `GEOIP,telegram,no-resolve`), Discord, WhatsApp, Instagram, Facebook, X (`GEOSITE,twitter`), TikTok, Netflix, Spotify, Twitch, Steam, GitHub, Apple, Microsoft. **Все сервисы** выбирает все чипы. |
| **Свои правила** | **Добавить правило**: **Тип**, **Значение** и для типов IP — **Не резолвить домены**. |

| Тип | Правило |
| --- | --- |
| **Домен и поддомены** | `DOMAIN-SUFFIX` |
| **Домен** | `DOMAIN` |
| **Слово в домене** | `DOMAIN-KEYWORD` |
| **Категория сайтов** | `GEOSITE` |
| **Категория IP** | `GEOIP` |
| **Диапазон IP** | `IP-CIDR`, или `IP-CIDR6`, если в значении есть двоеточие |
| **Приложение** | `PROCESS-NAME` |
| **Набор правил** | `RULE-SET` |

Неправильное значение показывает **Неверное значение**. Остальные типы совпадений пишутся в YAML; см. [Типы совпадений](../scenarios.md#match-types).

> [!NOTE]
> **Снимок экрана `route-traffic-picker`** — «Новый маршрут» с YouTube и Gemini и разделом «Свои правила»

> [!NOTE]
> **Снимок экрана `route-entry-form`** — «Категория сайтов» с ошибкой «Неверное значение»

## Редактор маршрута

Та же страница правит маршрут, **Остальной трафик** и программу группы подписки; у последних двух нет имени и трафика.

| Строка | Содержимое |
| --- | --- |
| **Название** | Имя маршрута и его группы. **Слишком длинное название** — длиннее 64 байт; **Это имя зарезервировано** — для зарезервированных имён; ошибка, если имя уже занято маршрутом или группой. |
| Трафик | Сводка вроде «YouTube и ещё 2»; открывает выбор трафика. |
| **Куда отправлять** | **Лучший сервер**: выбирает собственная группа маршрута. **Один сервер**: `to` на сервер или группу, выбранные через **Выбрать**. **Напрямую**: `to: DIRECT`, только для маршрутов. |
| **Как выбирать сервер** → **Поведение** | Профиль программы; для группы **Как настроено в группе** сохраняет собственный профиль группы. |
| **Порядок серверов** | `prefer` программы; см. [Порядок серверов](#server-order). |
| **Только серверы**, **Исключить серверы** | `pool.include` и `pool.exclude` через [конструктор условий](#conditions); у маршрутов есть только **Исключить серверы**. |

Для группы **Один сервер** держит группу на элементе без поиска (`to`), а **Все группы** его не предлагают. Ошибки поля показываются рядом с ним, остальные — в баннере; пока они есть, сохранение недоступно. Удаление убирает маршрут; его трафик уходит к следующему совпадению.

> [!NOTE]
> **Снимок экрана `route-editor`** — «▶️ YouTube» с названием, трафиком, «Лучший сервер», поведением и порядком

> [!NOTE]
> **Снимок экрана `route-editor-fixed`** — «Один сервер», выбирается «🇳🇴 Oslo 1»

> [!NOTE]
> **Снимок экрана `route-behaviour`** — «Встроенный», «От провайдера» и «Мои»

> [!NOTE]
> **Снимок экрана `route-pool`** — «Исключить серверы» с условием по имени

## Порядок серверов

Шаги — это уровни: решает первый шаг с рабочим сервером; см. [Уровни](../profiles.md#tiers).

| Часть | Смысл |
| --- | --- |
| **Добавить шаг** | Добавляет уровень. Сортировка меняет порядок; контекстное меню удаляет. |
| Пустой список | **Любой рабочий сервер**: своего порядка нет. |
| Приглушённые шаги | «Из поведения — измените шаг, чтобы задать свой порядок»: правка сначала копирует их. |
| Связка | «если ни один не работает» между шагами. |
| Подпись | В студии: «Если ни на одном шаге нет рабочего сервера: {action}» — `stranded` профиля. |

> [!NOTE]
> **Снимок экрана `route-editor-ladder`** — шаги «⚡ RU» и «Любой рабочий сервер» со связкой

### Шаги

**Серверы на этом шаге** собирают одно условие; должна выполняться каждая строка.

| Строка | Условие |
| --- | --- |
| **Название содержит** | `name ~ /text/i`, текст берётся буквально |
| **Страна** | `country in [..]`; с **Все, кроме этих стран** — `not country in [..]` |
| **Добавить условие** → Провайдер, Протокол, Тег, Поддерживает UDP, **Задержка меньше, мс** | `provider =`, `type =`, `tag()`, `udp`, `latency <` |
| **Добавить условие** → **Расширенное условие…** | Любое условие через [конструктор условий](#conditions) |
| **Другие условия** | Часть, которую строки показать не могут; правится как текст |

Подпись считает серверы, которые подходят сейчас, если условие можно проверить локально. **Метка** называет шаг; **Запасной вариант** задаёт `last-resort`.

> [!NOTE]
> **Снимок экрана `ladder-step-editor`** — «Название содержит: ⚡ RU», страна и «Сейчас подходят 2 сервера»

### Страны

**Выберите страны** показывает **На ваших серверах** (с числом серверов и пометкой **проверено**, когда страна выхода подтверждена), затем **Все страны**. Поиск ищет по коду и по английскому или русскому названию.

> [!NOTE]
> **Снимок экрана `country-picker`** — проверенные Норвегия, Швеция и Россия, затем «Все страны»

## Условия

Конструктор правит пулы, расширенные условия шагов, теги и **Распознаётся, когда** у типов сетей.

| Элемент | Содержимое |
| --- | --- |
| **Совпадение** | **Все условия** (`and`) или **Любое условие** (`or`). |
| **Условие {number}** | **Поле**, **Оператор** и **Значение**, **Значения через запятую** или **Шаблон** с **Без учёта регистра**. |
| **Как текст** | Текст условия, проверяется при вводе; ошибка разбора блокирует сохранение. |

Поля соответствуют разделу [Поля](../conditions.md#fields). Условие с вложенными группами показывает «Условие содержит вложенные группы, поэтому правится как текст.» Пустое условие читается как **Любой сервер**, а для сети — как **Всегда**.

> [!NOTE]
> **Снимок экрана `condition-builder`** — «Все условия»: страна — Норвегия или Швеция; задержка меньше 300

> [!NOTE]
> **Снимок экрана `condition-text`** — «Как текст» с ошибкой разбора
