# Обмен: экспорт, импорт и ссылки

Передать сценарий или профиль на другое устройство можно файлом, текстом или ссылкой.

Текстовый формат и сведения о пакетах: [руководство по обмену](../sharing.md).

## Экспорт

Откройте «Библиотеку», нажмите и удерживайте карточку и выберите **Экспорт**; также можно выбрать **Экспорт** в меню редактора сценария или студии.

> [!NOTE]
> **Снимок экрана `export-sheet`** — лист экспорта с тремя действиями.

| Действие | Результат |
| --- | --- |
| **Экспортировать в буфер обмена** | Копирует текст YAML. |
| **Скопировать ссылку** | Копирует ссылку `reclash://routing?p=…` со сжатым текстом. Уведомление: «Успешно скопировано». Лимит — 64 КиБ. |
| **Экспортировать файл** | Сохраняет файл `<name>.rcx.yaml`. |

### Отдельный документ или пакет

- Если элемент ссылается только на встроенные профили, экспортируется отдельный документ только с этим элементом.
- Если сценарий ссылается на ваши профили или профили провайдера, создаётся **пакет** со сценарием и всеми нужными профилями в одном файле. Он будет работать и на другом устройстве.

## Импорт

В меню центра маршрутизации с тремя точками выберите **Импорт**, затем **Импортировать из буфера обмена** или **Импортировать из файла**. Также принимается вставленная ссылка `reclash://routing?p=…` или HTTPS-ссылка на данные.

> [!NOTE]
> **Снимок экрана `import-page`** — страница «Импорт профиля маршрутизации» для одного сценария: заголовок, источник и описание.

На странице **«Импорт профиля маршрутизации»** показаны:

| Элемент | Значение |
| --- | --- |
| Список элементов **В этом файле** | Для нескольких элементов отображаются заголовок, тип («Сценарий» или «Профиль») и источник внизу. |
| Один элемент | Заголовок, уровень (для профилей) или «Сценарий», источник и описание. |
| **Проверить для группы {group}** | Профиль, импортируемый из листа группы, проверяется для этой группы. |
| **Сайты, к которым будет выполнено подключение** | Узлы; где нужно, помечены как сторонние. |
| **Предупреждения** | Неблокирующие замечания. |
| Баннер | Ошибки; первая ошибка отключает сохранение. |

> [!NOTE]
> **Снимок экрана `import-bundle`** — страница импорта пакета со сценарием и двумя профилями.

Нажмите **Добавить в мои профили**. Уведомление: «Добавлен профиль “{profile}”». Элементы помещаются в раздел **Мои**; сценарий сам по себе не запускается.

### Переименование при совпадении имён

Если заголовок уже существует, импортёр добавляет к новому элементу номер, а не перезаписывает существующий.

### Проблемы

| Сообщение | Значение |
| --- | --- |
| «Запустите ядро приложения, чтобы проверить этот профиль» | Core не запущен, поэтому проверить файл нельзя. Запустите подключение и повторите попытку. |
| Баннер с ошибкой разбора | Файл некорректен; см. [устранение неполадок](troubleshooting.md). |
| Запрос согласия | Импортируемый элемент обращается к узлам; разрешить это можно после импорта. |

> [!NOTE]
> **Снимок экрана `import-problems`** — страница импорта с баннером ошибки и отключённой кнопкой сохранения.

## Пошагово: передача настройки на другое устройство

На устройстве, где уже настроен сценарий «Моё разделение»:

1. Откройте **Автоматическую маршрутизацию**, вкладку **Библиотека** и фильтр **Сценарии**.
2. Нажмите и удерживайте **Моё разделение**, выберите **Экспорт**.
3. Выберите **Скопировать ссылку**. Появится сообщение «Успешно скопировано». (Для файла выберите **Экспортировать файл**.)
4. Отправьте ссылку себе в сообщении.

На другом устройстве:

1. Откройте ссылку в ReClash либо скопируйте её и выберите **Автоматическая маршрутизация** → меню с тремя точками → **Импорт** → **Импортировать из буфера обмена**.
2. Проверьте страницу: заголовок, элементы, раздел **Сайты, к которым будет выполнено подключение**.
3. Нажмите **Добавить в мои профили**.
4. Перейдите на вкладку **Обзор**, нажмите **Изменить** и выберите **Моё разделение**.

Чтобы шаги нашли нужные серверы, на другом устройстве в подписке должны быть серверы, упомянутые в настройке (⚡ RU, Stockholm). Сама настройка переносима.
