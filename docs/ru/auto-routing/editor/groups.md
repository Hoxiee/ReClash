# Лист группы

Лист группы в «Прокси»: состояние, управление, способ выбора сервера, подробности и сообщения.

## Разделы

Лист открывается действием автомаршрутизации у группы-селектора в **Прокси**, из строки группы на странице [«Автомаршрутизация»](hub.md) или из строки группы в разделе **Группы в сценарии** работающего сценария.

| Раздел | Содержимое |
| --- | --- |
| Проблемы | Проблема группы; см. [Сообщения](#messages). |
| **Нужно разрешение** | «„{profile}“ хочет проверить эти сайты», узлы, **Разрешить**. До тех пор группа работает на `builtin/simple`. |
| Состояние | Сервер, причина, прогноз, страна выхода, шаг, тип сети, задержка. **Сменить сервер** ставит текущий сервер на 15 минут и переключает; недоступно в режиме «Вручную». |
| **Управление** | **Авто**, **Закреплён** или **Вручную**; см. [Управление](#control). Если группой управляет сценарий, внизу: «Сейчас этой группой управляет сценарий «{scenario}».» |
| Как группа выбирает | **Поведение**, **Порядок серверов**, **Серверы**, **Переключения** и **Частота проверок**; см. [Как группа выбирает](#how-the-group-picks). |
| **Сеть** | **Прямые сайты через эту группу**, если у поведения есть `direct-split`: **Включено сейчас** или **Ждёт: прямые сайты пока открываются**. |
| **Подробности** | «Сравнено {count} серверов»; открывает **Почему этот сервер** (первые 8 строк ранжирования) и **История** (последние 20 записей журнала); см. [Объяснение](#explanation). |
| **Настройки автомаршрутизации** | Открывает [«Автомаршрутизацию»](hub.md). |
| **Создана маршрутом** или **Выключить автомаршрутизацию для этой группы** | Группа маршрута ведёт на **Изменить маршрут** (открывает редактор маршрута). Иначе, для группы с собственной привязкой пользователя, убирает её; группа сохраняет свой сервер. |

Без привязки группа показывает **Если включить автомаршрутизацию** (поведение, которое она получит, и число серверов) и **Включить автомаршрутизацию**: это добавляет привязку пользователя с поведением по умолчанию.

## Управление

| Вариант | Управление движком |
| --- | --- |
| **Авто** | `auto`: решение принимается; закрепление снимается. |
| **Закреплён** | `pin` на текущий сервер во всех сетях: держится, пока работает, и возвращается к нему после восстановления. |
| **Вручную** | `manual`: пользователь выбирает в списке прокси; движок никогда не переключает и не проверяет. |

Ручной выбор сервера в группе «Авто» закрепляет его. См. [Управление](../engine.md#control).

## Как группа выбирает

Единственное место, где видно и меняется, как группа выбирает сервер. Каждая строка показывает источник значения: **Из сценария «{scenario}»**, **Ваше для этой группы** или **Из поведения «{behaviour}»**. Группа, закреплённая за одним элементом, показывает только **Через {member}**.

| Строка | Что правит |
| --- | --- |
| **Поведение** | `profile`; выбор из **Встроенный**, **От провайдера** и **Мои** либо **Как настроено в группе** в программе сценария. |
| **Порядок серверов** | `prefer`, через [редактор шагов](routes.md#server-order). Пустой — следует поведению. |
| **Серверы** | Пул; см. [Серверы](#servers). |
| **Переключения** | `feel`: **Редко** (`calm`), **Сбалансированно**, **Часто** (`eager`). |
| **Частота проверок** | `energy`: **Экономно**, **Сбалансированно**, **Точно**. |

### Куда сохраняется изменение

Изменение попадает в слой, который уже задаёт это поле: программу работающего сценария для этой группы (или его маршрут), иначе привязку пользователя. В программе сценария **Все группы** (`*`) изменённое поле создаёт программу с именем группы, а не меняет все группы. Встроенный сценарий и сценарий провайдера копируются в **Мои** перед первым изменением. **Переключения** и **Частота проверок** всегда идут в привязку.

### Серверы

Строка **Серверы** открывает **Выбирать из**; каждый выбор задаёт `pool.include` и возвращает закреплённую группу в «Авто».

| Часть | Пул |
| --- | --- |
| **Любой** | Без сужения. |
| Чипы провайдера и пользователя | `chips` привязки. |
| Флаги | До 8 флагов из имён серверов, самые частые первыми, если флагов хотя бы два. |
| **Шаблон имени** | Сохраняется как `name ~ /pattern/i`; не принимается, пока он неверен или ничего не находит («Подходят {count} из {total}»). |

Контекстное меню чипа пользователя удаляет его. Ниже **Только серверы** и **Исключить серверы** открывают [конструктор условий](routes.md#conditions).

## Объяснение

**Подробности** открывают два раздела. Каждая строка **Почему этот сервер** показывает сервер и задержку, затем причину исключения либо уровень и здоровье (**Работает**, **Работал раньше**, **Не проверялся**, **Не работает**), «может попасть в «{tier}» после проверки», «выход {country}», результаты проверок (✓ прохождение, × сбой, ~ мягкий сбой) и время последней проверки. **История** перечисляет переключения, сбои, закрепления и смены режима. Поля: [Объяснения и журнал](../engine.md#explanations-and-journal).

| --- | --- |
| Управление вручную | `manual.requested` |

| Сценарий держит {node} · Сценарий переключает на {node} · {node} нет в этой группе | `hold.fixed` · `switch.fixed` · `fixed.missing` |
| Пауза, пока сеть — «{kind}»: ничего не проверяется и не переключается | `hold.paused` |
| Не используется: режим {mode} | `hold.idle` |
| Нет рабочих серверов; держит текущий · Нет рабочих серверов; запасной вариант — {node} | `stranded.no-candidates` · `switch.stranded` |
| Выбран лучший доступный сервер | `switch.initial` |
| Сервер сменён; {from} пропускается 15 минут | `switch.change-server` |
| {from} перестал работать; переключено на лучший запасной | `switch.failover` |
| {from} больше не входит в список | `switch.out-of-pool` |
| Нет другого рабочего сервера | `hold.no-alternative` |
| Это лучший сервер | `hold.best` |
| Проверяет лучшего кандидата | `hold.checking` |
| Работает; держится до сбоя | `hold.working` |
| Недавно переключался; выжидает перед следующим | `hold.dwell` |
| Достигнут лимит переключений ({limit} в час) | `hold.flap-limit` |
| Более быстрому серверу нужен ещё один замер | `hold.confirming` |
| Перешёл на сервер из «{tier}» · Ушёл с {from}: быстрее на {gain} мс | `switch.better-tier` · `switch.faster` |
| Не удалось выбрать сервер | `select.failed` |
| Похоже, пропала сеть; серверы не виноваты · Сеть сменилась | `network.suspect` · `network.changed` |
| Прямые сайты теперь идут через эту группу · Прямые сайты снова идут напрямую | `split.on` · `split.off` |
| Не входит в список · Исключён поведением · Не сервер · Пропущен после «Сменить сервер» · Не подходит ни под одно предпочтение · Ещё не проверен | `pool.no-match` · `pool.excluded` · `pool.unroutable` · `cooldown` · `no-tier` · `pending` |
| Поведение {profile} не найдено; используется стандартное | `profile.missing` |
| Ошибка поведения: {error} | `profile.invalid` |
| В текущей конфигурации эта группа не селектор · В группе нет серверов | `group.unavailable` · `group.empty` |
| Маршрут «{route}» пропущен: группа с таким именем уже есть. | `route.name-taken` |
| Маршрут «{route}» направляет трафик в «{to}», которого нет в поведении. | `route.to-missing` |
| Маршрут «{route}» не применён: {error} | `route.invalid` |
| Не удалось сохранить состояние маршрутизации: {error} | `store.failed` |

Строка прогноза называет конец удержания: «Перейдёт на {node}, как только проверка это подтвердит», «Может перейти на {node} через {minutes} мин» или «Перейдёт на {node}, если он останется быстрее на {gain} мс». Неизвестный код показывается как есть.
