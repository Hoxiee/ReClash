# Лист группы

Лист группы позволяет следить за одной группой и управлять ею. Он находится в разделе **Прокси**: выберите группу (лист есть только у групп select) и нажмите **Автоматическая маршрутизация** в верхней панели либо используйте то же действие в строке группы. Лист также открывается из строк центра маршрутизации. Заголовок листа — имя группы.

Разделы сверху вниз (некоторые отображаются только при наличии содержимого):

1. Проблемы красным текстом, например отсутствующий профиль.
2. **Требуется разрешение**, если профиль ожидает согласия.
3. Карточка состояния и **Сменить сервер**.
4. **Управление**.
5. **Изменить на**.
6. **Поведение**.
7. **Почему выбран этот сервер**.
8. **История**.
9. **Настройки автоматической маршрутизации**.
10. **Создано маршрутом** или **Выключить автоматическую маршрутизацию для группы**.

> [!NOTE]
> **Снимок экрана `group-sheet-auto`** — лист основной группы в режиме Auto: карточка состояния, управление, чипы «Изменить на» и раздел поведения.

## Группа без автоматической маршрутизации

Для группы без авто-маршрутизации показываются краткое описание, раздел **При включённой автоматической маршрутизации** (профиль по умолчанию с описанием и числом серверов) и основная кнопка.

1. Откройте лист группы.
2. Прочитайте подсказку: «ReClash оставляет в группе работающий сервер и переключается, если он перестаёт работать. Проверки выполняются только при использовании сети».
3. Нажмите **Включить автоматическую маршрутизацию**.

Группа получает собственную привязку с профилем по умолчанию. Чтобы отменить это, см. [отключение авто-маршрутизации для группы](#выключить-автоматическую-маршрутизацию-для-одной-группы).

> [!NOTE]
> **Снимок экрана `group-intro`** — лист группы без автоматической маршрутизации с кнопкой включения.

## Карточка состояния

Верхняя карточка показывает:

| Элемент | Значение |
| --- | --- |
| Имя сервера | Текущий сервер; если в имени нет флага, перед ним отображается флаг страны. |
| Причина | Почему выбран этот сервер, например «Работает; будет использоваться до отказа». Коды см. в [troubleshooting.md](troubleshooting.md#причины-на-карточке-состояния). |
| Прогноз | Что может произойти: например, «Возможно переключение на {node} через {minutes} мин», «Переключится на {node}, когда проверка подтвердит» или «Переключится на {node}, если преимущество останется {gain} мс». |
| Подробности | Название страны, шага и «Сеть: {kind}», разделённые символом «·». |
| Задержка | Справа в мс, если известна. |
| **Сменить сервер** | Кнопка под карточкой: переключает на лучший другой сервер и исключает текущий на 15 минут. Недоступна в режиме Manual. |

## Управление: Auto, Pinned, Manual

**Управление** — переключатель из трёх вариантов. Под ним объясняется выбранный режим.

| Вариант | Подсказка | Что происходит |
| --- | --- | --- |
| **Auto** | Выбирает лучший работающий сервер в порядке серверов и переключается при его отказе. | Решение принимает поведение. |
| **Pinned** | Остаётся на {node}; переключается с него только при отказе и возвращается после восстановления. | Закрепляет текущий сервер (он должен быть выбран). Если он откажет, авто-маршрутизация переключится и вернётся, когда сервер заработает. |
| **Manual** | Вы выбираете сервер в списке прокси; авто-маршрутизация не переключает его. | Серверы выбираются в списке группы, авто-маршрутизация только наблюдает. |

Чтобы вернуться в Auto, нажмите **Auto**. Выбор пула в разделе **Изменить на** при закреплённом сервере также включает Auto.

> [!NOTE]
> **Снимок экрана `group-sheet-pinned`** — для управления выбрано Pinned, на карточке написано «Удерживается закреплённый сервер».

## Изменить на

Раздел скрыт, если группа закреплена за одним элементом (в этом случае строка поведения показывает «Через {member}»). Одно нажатие ограничивает группу пулом серверов и переключает на лучший. Чипы и кнопка «плюс» отключены в режиме Manual.

| Элемент | Действие |
| --- | --- |
| Чип **Любой** | Не сужает пул. |
| Чипы | Пулы провайдера, пользовательские пулы и флаги из имён серверов. Чипы-флаги появляются только при наличии серверов как минимум из двух стран; сначала отображаются самые частые, не более 8. |
| **Добавить шаблон** (кнопка «плюс») | Запрашивает **Шаблон имени** (регулярное выражение, без учёта регистра сопоставляется с именами серверов). В диалоге указано «Совпадает: {count} из {total}»; пустое совпадение и некорректный шаблон не принимаются. Новый чип сразу выбирается. |
| Долгое нажатие (или правый щелчок) на пользовательский чип | **Удалить**. У чипов провайдера и флагов меню нет. |

> [!NOTE]
> **Снимок экрана `group-change-to`** — чипы Any, 🇳🇴, 🇸🇪, 🇷🇺 и пользовательский шаблон.

## Раздел «Поведение»

| Строка | Открывает |
| --- | --- |
| Профиль (заголовок, описание или уровень **Simple**/**Advanced**) | Выбор **Профиля** с разделами **Встроенные**, **От провайдера**, **Мои**. У профиля показывается описание и, если требуется согласие, «Требуется разрешение». Для группы провайдера отображаются только его предложения. Внизу написано, что профили создаются в «Дополнительные настройки» → «Автоматическая маршрутизация». |
| **Порядок серверов** | Страница собственного порядка серверов группы (скрыта, если группа закреплена на одном элементе). Подзаголовок — сводка, например «1 ⚡ RU → 2 Любой работающий сервер». См. [страницу порядка серверов](#страница-порядка-серверов). |
| **Настройки группы** | [Страница настроек](#страница-настроек), подзаголовок «Переключение: … · Проверки: …». |

Внизу раздела отображается проблема профиля (если есть), а при управлении группы сценарием — «Сценарий «{scenario}» управляет этой группой». Если программа сценария отличается от имени группы, строка профиля также указывает цель программы (например, основная группа или все группы).

Приоритет порядка серверов от высшего к низшему: порядок сценария для группы, порядок, настроенный для группы, порядок профиля. Шаг крайнего резерва уступает всем остальным, даже записанным ниже.

> [!NOTE]
> **Снимок экрана `group-behaviour`** — раздел поведения с профилем Fastest, сводкой порядка серверов и строкой настроек.

## Страница порядка серверов

Заголовок страницы — **Порядок серверов**, в панели заголовка показано имя группы. Здесь редактируется собственный порядок группы тем же [редактором шагов](routes.md#редактор-порядка-серверов), что и для маршрутов.

- Если собственных шагов нет, шаги профиля показаны серым текстом с подсказкой «Из поведения — измените шаг, чтобы создать собственный порядок». Редактирование или добавление шага создаёт копию. Удалите все шаги, чтобы снова следовать профилю.
- В каждой строке есть номер шага, метка или условие, отметка **Последний резерв** и число серверов («{count} серверов», красным при нуле). Подсвечивается шаг, к которому относится текущий сервер.
- Подпись «если ни один не работает» соединяет шаг 1 со шагом 2.
- Кнопка «плюс» (**Добавить шаг**) создаёт шаг. При двух или более шагах можно перетаскивать их кнопкой сортировки. Долгое нажатие (или правый щелчок) открывает **Удалить**.
- Внизу: «Этот порядок действует только для этой группы. Оставьте его пустым, чтобы следовать порядку профиля». Если группой управляет сценарий: «Сейчас этой группой управляет сценарий: заданный им порядок серверов имеет приоритет над этим».

## Страница настроек

> [!NOTE]
> **Снимок экрана `group-settings`** — страница настроек: шаблон имени «Совпадает 4 из 5», переключение Balanced, проверки Economical и переключатель прямых сайтов.

| Раздел | Настройка | Примечания |
| --- | --- | --- |
| **Серверы** | **Шаблон имени** | Регулярное выражение (подсказка «Любой»), применяется после Enter и только если корректно. Пустое значение означает любой сервер. Внизу отображается «Совпадает {count} из {total}» или «Шаблон не является корректным регулярным выражением». |
| **Поведение** | **Переключение** | **Редко**, **Сбалансированно**, **Часто**. Насколько активно группа переключается с работающего сервера на более подходящий. |
| | **Проверки** | **Экономно**, **Сбалансированно**, **Точно**. Число запросов для проверок. |
| **Сеть** | **Прямые сайты через эту группу** | «Если сайты, направляемые правилами напрямую, перестают открываться, они идут через эту группу. Локальные адреса всегда остаются прямыми». Показывается только для поддерживаемых групп. После включения отображается **Сейчас активно** или **Готово: прямые сайты всё ещё открываются**. |

## Почему выбран этот сервер и история

**Почему выбран этот сервер** — раскрываемая строка, видимая при наличии рейтинга. В свёрнутом виде показывает «Сравнено серверов: {count}»; в раскрытом — до 8 серверов. В строке указаны сервер и его задержка; текущий сервер подсвечен. Под именем отображаются:

- причина исключения либо шаг и состояние;
- «может перейти в “{tier}” после проверки», если проверка может повысить его;
- подтверждённая страна выхода: «выход {flag} {code}»;
- результаты проверок со значками: ✓ пройдена, × ошибка, ~ мягкая ошибка;
- сколько времени прошло с последней проверки.

У исключённого сервера указана одна из причин: «Не в пуле», «Исключён профилем», «Не сервер», «Пропущен после “Сменить сервер”», «Не соответствует предпочтениям», «Ещё не проверен». Состояние обозначается как **Работает**, **Раньше работал**, **Не проверен** или **Не работает**.

> [!NOTE]
> **Снимок экрана `group-why`** — раскрытый раздел с пятью строками, включая «Пропущен после “Сменить сервер”».

**История** — раскрываемая строка, появляющаяся после первого события. В свёрнутом виде показывает последнее событие; в раскрытом — 20 последних, от новых к старым, с возрастом каждой записи. Примеры:

- переключения: «{from} → {to}: причина»;
- сбой: «{node} перестал работать»;
- закрепление: «Закреплено: {node}»;
- смена режима: «Режим {from} → {to}».

> [!NOTE]
> **Снимок экрана `group-history`** — история раскрыта, показаны переключение при отказе и закрепление.

## Настройки автоматической маршрутизации

Строка **Настройки автоматической маршрутизации** («Профили, сценарии и маршруты») закрывает лист и открывает [центр маршрутизации](hub.md). Если лист открыт из центра, строка просто закрывает его.

## Согласие

Некоторые профили связываются с сайтами для выполнения проверок. Пока вы не разрешили доступ, группа использует Simple.

1. Откройте лист группы. Вверху появится раздел **Требуется разрешение** с текстом «Профиль «{profile}» хочет проверять эти сайты» и перечнем узлов.
2. Нажмите **Разрешить**.

Внизу пояснение: «Пока вы не разрешите доступ, группа использует профиль Simple. Сайты посещаются только через ваши серверы или для проверки сети».

Такой же раздел для сценария есть в центре маршрутизации; см. [hub.md#consent](hub.md#согласие).

> [!NOTE]
> **Снимок экрана `group-consent`** — раздел разрешений со списком узлов и строкой «Разрешить».

## Группы маршрутов

У группы, созданной маршрутом, вместо строки отключения отображается раздел **Создано маршрутом**. Строка **Изменить маршрут** поясняет: «Маршрут в сценарии «{scenario}» создал эту группу. Измените или удалите его там» и показывает стрелку. Нажатие закрывает лист и открывает маршрут во вкладке «Маршруты» центра (Дополнительные настройки → Автоматическая маршрутизация).

> [!NOTE]
> **Снимок экрана `group-route`** — лист группы «▶️ YouTube» с разделом «Создано маршрутом».

## Выключить автоматическую маршрутизацию для одной группы

1. Откройте лист группы.
2. Внизу нажмите красную кнопку **Выключить автоматическую маршрутизацию для этой группы**.

Удаляется собственная привязка группы. Внизу написано: «Группа сохраняет текущий сервер и перестаёт переключаться самостоятельно». Строка видна только для группы с собственной привязкой и никогда не отображается для группы маршрута. Если сценарий всё ещё управляет группой, измените сценарий ([hub.md#turn-auto-routing-off](hub.md#выключение-автоматической-маршрутизации)).
