# API предпросмотра провайдера ReClash

Версия 1 предоставляет управляемые провайдером сведения для отображения до импорта подписки. Этот API отделён от загрузки конфигурации и заголовков провайдера, применяемых к сохранённым профилям. Провайдер реализует этот эндпоинт только для чтения; ReClash обнаруживает его и получает данные.

## Обнаружение

Верните обычную страницу подписки для браузера, содержащую ровно одну ссылку:

```html
<link rel="reclash-preview" href="/reclash/preview/account-scoped-token">
```

Относительные URL разрешаются относительно итогового URL страницы. Эндпоинт должен иметь тот же origin (схему, имя узла и порт), что и страница, не должен совпадать с самой страницей и не должен содержать фрагмент. ReClash не проверяет стандартные пути и не запускает JavaScript для обнаружения API. Если нужны персонализированные данные, используйте в URL непрозрачный токен, привязанный к учётной записи; не требуйте HWID или входа через браузер.

## Запрос и ответ

ReClash отправляет GET с заголовком `Accept: application/json` и User-Agent браузерного предпросмотра. В API-запрос не передаются HWID, сведения об устройстве, клиентский пресет подписки, cookies, заголовок авторизации или Referer. Перенаправления выполняются существующим транспортом с ограничениями; принимается только итоговый JSON-ответ с тем же origin.

Верните `Content-Type: application/json` и не более 64 КиБ JSON в UTF-8:

```json
{
  "version": 1,
  "provider": {
    "name": "Example VPN",
    "description": "Contact support if you need help installing your subscription.",
    "logoUrl": "/assets/provider-logo.png",
    "supportUrl": "https://t.me/example_support"
  },
  "account": {
    "name": "Personal account"
  },
  "subscription": {
    "type": "test"
  }
}
```

Все поля, кроме целочисленного `version`, необязательны. Неизвестные поля игнорируются. Длина имени ограничена 256 символами, описания — 4096. Текст отображается как обычный текст, а не HTML или исполняемый Markdown. Некорректные поля не заменяют полезные метаданные страницы. При неподдерживаемой версии, ошибочном JSON, слишком большом ответе или сбое запроса показывается страница панели, но импорт не блокируется.

- `provider.name`: название сервиса в заголовке окна подтверждения.
- `provider.description`: описание провайдера в основном тексте окна подтверждения.
- `provider.logoUrl`: абсолютный HTTP(S)-адрес изображения или адрес относительно ответа. HTTPS-страницы не могут перенаправляться на HTTP. Поддерживаемые типы ответа: PNG, JPEG, WebP, GIF, SVG и ICO (в зависимости от поддержки декодера). Изображения размером более 512 КиБ не показываются. Если загрузка не удалась, остаётся монограмма; внешние ресурсы SVG виджет не загружает.
- `provider.supportUrl`: HTTP(S)-адрес или проверенный адрес Telegram. Относительные ссылки разрешаются относительно URL API. Действие поддержки появляется в верхней панели и использует существующий сценарий подтверждения для внешних ссылок и Telegram; автоматически ссылка не открывается.
- `account.name`: отображаемое имя учётной записи; оно показано отдельно от провайдера и редактируемого локального имени профиля.
- `subscription.type`: `test`, `promo` или `dev`, не более 32 символов. В окне подтверждения под именем показывается метка; неизвестное значение не отображается. То же значение в заголовке `reclash-subscriptiontype` помечает сохранённый профиль.

Приоритет данных: корректные поля API выше распознанного оформления панели, а оно выше общих HTML-метаданных. Если поле API отсутствует, сохраняется значение с более низким приоритетом. Запрос логотипа не отправляет cookies сеанса, авторизацию, Referer или идентификатор устройства — даже для изображения с тем же origin. Скрипты, стили, списки приложений, адреса телеметрии и URL конфигураций из JSON не запускаются и не открываются.

## Требования к провайдеру

Страница, эндпоинт предпросмотра и логотип ДОЛЖНЫ быть безопасны для чтения до получения согласия. Они НЕ ДОЛЖНЫ регистрировать устройство, занимать слот устройства, помечать конфигурацию подписки как загруженную или менять состояние учётной записи/подписки. Не помещайте в этот ответ ключи конфигурации или подключения. Для ответов с данными учётной записи используйте `Cache-Control: private, no-store`; никогда не записывайте приватные токены в журналы и не помещайте их в общедоступный кэш.

ReClash не может обеспечить только чтение на стороне сервера. Обычная загрузка подписки и настроенная идентификация устройства начинаются только после нажатия «Добавить». Данные предпросмотра используются только для отображения: они не могут менять настройки приложения, маршрутизацию, транспортный идентификатор, выбранный клиент или сохранённый URL подписки и не сохраняются как достоверные метаданные подписки.

## Существующие панели

Без этого API ReClash по-прежнему распознаёт встроенные данные учётной записи Remnawave и `brandingSettings` браузера, встроенные данные страницы 3x-ui, стандартные поля учётной записи Marzban, а также общие HTML-метаданные и явные ссылки поддержки. Для Remnawave временный сеанс страницы используется только для одно-origin-ресурса оформления браузера `/assets/.app-config-v2.json`, но не для API или логотипа. Пользовательские темы могут добавить ссылку обнаружения, чтобы подключить этот контракт без изменения доставки подписки.
