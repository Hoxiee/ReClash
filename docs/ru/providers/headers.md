# Заголовки ответа

Правила разбора, форматы значений и поля аккаунта, панели, сообщений и напоминаний, которые может нести ответ подписки.

Все поля, синонимы и ограничения — в [«Реестре стандарта»](standard.md). Поля настроек приложения — в [«Настройках приложения»](app-settings.md), `reclash-routing` — в [«Доставке маршрутизации»](routing.md), заголовки устройства — в [«Заголовках запроса»](request.md#device-status).

## Разбор

- Имена заголовков не зависят от регистра.
- Поле читается из канонического заголовка. Синоним читается, только если канонического заголовка нет, поэтому некорректное каноническое значение никогда не заменяется синонимом.
- Поле, отправленное больше одного раза, игнорируется: `Duplicate singleton`.
- Некорректное значение отбрасывается: `Invalid provider field`. Остальной ответ применяется.
- Неизвестный заголовок `reclash-*` или `flclashx-*` выдаёт предупреждение: `Unsupported provider field`.
- Значение заголовка больше 8 КиБ или всех заголовков больше 64 КиБ — загрузка завершается ошибкой.
- Поле, которого нет в ответе, отзывается; поля расхода остаются устаревшими ([«Время жизни метаданных»](README.md#metadata-lifetime)).
- Пустое значение допустимо для `text`, `tokens`, `numbers`, `hosts` и `packages` и заменяет сохранённое. Поля `url`, `integer` и `boolean` очистить нельзя.

### Комментарии в теле

Если хостинг не позволяет задать заголовки, поставьте метаданные первыми в теле строками-комментариями.

```yaml
#reclash-servicename: Example VPN
#reclash-supporturl: https://t.me/example_support
#reclash-announce: base64:0J/RgNC40LzQtdGAIFZQTg==
proxies:
  - name: Germany
```

- Читаются только строки до первой строки, которая не комментарий и не пустая, в пределах первых 64 КиБ.
- Имя — любой заголовок поля или синоним из реестра, а при пресете FlClashX — ещё и имена `flclashx-*`.
- Для одного поля HTTP-заголовок важнее комментария.
- `Subscription-Userinfo` и заголовки устройства читаются только из HTTP.

## Форматы значений

| Тип | Синтаксис | Правила |
| --- | --- | --- |
| `text` | UTF-8, или `base64:` / `base64,` и Base64 от UTF-8 | Не больше 1024 байт после декодирования, если поле не указывает иное. Без управляющих символов; LF допустим в `reclash-announce` и `reclash-notice`. |
| `url` | Абсолютный URL `http` или `https` | Нужен хост. Без userinfo, пробелов и управляющих символов. Не больше 1024 символов. |
| `integer` | Десятичное число | Умножается на масштаб синонима, затем проверяется диапазон. |
| `boolean` | `1`, `true`, `yes` / `0`, `false`, `no` | Без учёта регистра. |
| `tokens` | Через запятую | Приводятся к нижнему регистру, дубликаты убираются. Каждый токен соответствует `^[a-z0-9._:#-]{1,64}$`; один плохой токен делает поле некорректным. |
| `numbers` | Целые через запятую | Сортируются, дубликаты убираются, не больше 8. Одно некорректное или выходящее за диапазон число делает поле некорректным. |
| `hosts` | `host[:port]` через запятую | Приводятся к нижнему регистру; префикс `https://` и завершающий `/` отбрасываются. Одна некорректная запись делает поле некорректным. |
| `packages` | Имена пакетов Android через запятую или пробел | Некорректное имя отбрасывается отдельно, с предупреждением. Не больше 255 символов на имя; больше 512 имён делают поле некорректным. |

`reclash-buyplan` и `reclash-buytraffic` принимают необязательное целое после последней запятой. Целое вне диапазона отбрасывается с предупреждением; основное значение применяется.

## Subscription-Userinfo

```http
Subscription-Userinfo: upload=455727941; download=6174315083; total=107374182400; expire=1798761600
```

| Ключ | Значение |
| --- | --- |
| `upload`, `download` | Израсходованные байты. |
| `total` | Квота в байтах. `0` — без ограничения. |
| `expire` | Unix-время в секундах. `0` — бессрочно. |

Ключи не зависят от регистра и разделяются `;`. Значения — неотрицательные числа, дробная часть отбрасывается; `expire` не больше `8640000000000`. Повторённый ключ отбрасывается.

## Имя профиля

Профиль, которому пользователь не дал имя, получает первое доступное из:

1. имени файла из `Content-Disposition` (`filename*`, затем `filename`);
2. `profile-title` (text, 160 Б);
3. `reclash-servicename`;
4. хоста подписки.

Имя, заданное пользователем, никогда не заменяется.

## Панель провайдера

| Заголовок | Тип | Где показывается |
| --- | --- | --- |
| `reclash-servicename` | text, 160 Б | Имя сервиса на карточке дашборда и в окне импорта. |
| `reclash-servicelogo` | url | Логотип на простом дашборде. |
| `reclash-servicelogodark` | url | Логотип в тёмной теме. Если не задан, берётся `reclash-servicelogo`. |
| `reclash-supporturl` | url | Действие «Поддержка». Принимает также `https://t.me/…`, `https://telegram.me/…` и ссылки `tg://`, например `tg://resolve?domain=…`. |
| `reclash-webpageurl` | url | Действие «Сайт». |
| `reclash-subscriptiontype` | text, 32 Б | Значок в окне импорта и списке профилей: `test`, `promo` или `dev`. Другие значения значка не дают. |
| `reclash-hideurl` | boolean | Скрывает URL в редакторе профиля и окне импорта. Секретным URL он не делает. |
| `reclash-serverinfo` | text, 256 Б | Группа прокси, выбранный узел которой показывает простой дашборд. Сравнивается без учёта регистра. |

## Сообщения

| Заголовок | Тип | Поведение |
| --- | --- | --- |
| `reclash-announce` | text, многострочный, 1024 Б | Описание. Показывается в окне импорта и в карточке дашборда над виджетами, которую пользователь не может ни переместить, ни убрать. |
| `reclash-announceurl` | url | Ссылка в карточке описания. |
| `reclash-notice` | text, многострочный, 1024 Б | Закрываемое уведомление на дашборде. Закрытие запоминается для этого текста и ссылки; при их изменении уведомление появится снова. |
| `reclash-noticeurl` | url | Ссылка в уведомлении. |

Чтобы убрать сообщение, отправьте его заголовок с пустым значением.

```http
reclash-notice: base64:0J/Qu9Cw0L3QvtCy0YvQtSDRgNCw0LHQvtGC0YsgMSDQvdC+0Y/QsdGA0Y8gMDI6MDDigJMwMzowMCDQnNCh0JouCtCf0L7QtNC60LvRjtGH0LXQvdC40LUg0LzQvtC20LXRgiDQv9GA0LXRgNGL0LLQsNGC0YzRgdGPLg==
reclash-noticeurl: https://status.example.net
```

## Продление и напоминания

| Заголовок | Значение | Действие |
| --- | --- | --- |
| `reclash-buyplan` | `url[,дни]`, дни 1–3650 | Действие продления, предлагается начиная с `дни` до конца срока. |
| `reclash-buytraffic` | `url[,процент]`, процент 1–100 | Действие докупки трафика, предлагается начиная с `процент` израсходованной квоты. |
| `reclash-expiredays` | numbers 0–365 | За сколько дней до конца срока приходит уведомление. По умолчанию `3,2,1`. |
| `reclash-trafficpercent` | numbers 1–100 | Процент израсходованной квоты, при котором приходит уведомление. По умолчанию `90`. |

- Напоминаниям нужен `Subscription-Userinfo`. Напоминания о сроке не приходят при `expire=0`, о трафике — при `total=0`.
- Каждый порог срабатывает один раз на дату окончания. Порог трафика снова взводится, когда расход опускается ниже него.
- Пока поле расхода устарело, напоминания не приходят.
- Действие уведомления о трафике — докупка (если `процент` не задан или достигнут), иначе продление (если `дни` не заданы или достигнуты), иначе поддержка.
- На дашборде продление появляется начиная с `дни` до конца срока или, если `дни` не заданы, с наибольшего порога срока. Докупка появляется начиная с `процент` израсходованной квоты или, если он не задан, с наименьшего порога трафика.

## Интервал обновления

`reclash-autoupdateinterval` задаёт интервал автообновления в минутах, 5–43200. Синоним `profile-update-interval` — в часах. Значение действует, только пока в редакторе профиля включён переключатель «Использовать интервал провайдера»; по умолчанию он выключен.

## Имена FlClashX

С пресетом клиента FlClashX заголовки и комментарии `flclashx-*` отображаются на поля ReClash; другие пресеты их игнорируют. Канонический заголовок `reclash-*` важнее своего аналога из FlClashX.

| FlClashX | ReClash |
| --- | --- |
| `flclashx-servicename`, `-servicelogo`, `-supporturl`, `-webpageurl`, `-buyplan`, `-buytraffic`, `-autoupdateinterval`, `-hideurl`, `-serverinfo`, `-widgets`, `-background`, `-view`, `-settings` | `reclash-` с тем же окончанием |
| `flclashx-special` | `reclash-restrictions` |
| `flclashx-newdomain` | `reclash-fallbackhosts` |
