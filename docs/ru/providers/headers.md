# Заголовки ответа

Стандартные HTTP-заголовки, которые может нести ответ подписки, форматы их значений и единственный заголовок `reclash-config`, указывающий на манифест провайдера.

Все заголовки, синонимы и ограничения — в [«Реестре стандарта»](standard.md). Всё остальное, что провайдер сообщает ReClash, — в [«Манифесте провайдера»](manifest.md); заголовки устройства — в [«Заголовках запроса»](request.md#device-status).

## Разбор

- Имена заголовков не зависят от регистра.
- Поле читается из канонического заголовка. Синоним читается, только если канонического заголовка нет и манифест не задаёт поле, поэтому некорректное каноническое значение никогда не заменяется синонимом.
- Поле, отправленное больше одного раза, игнорируется: `Duplicate singleton`.
- Некорректное значение отбрасывается: `Invalid provider field`. Остальной ответ применяется.
- Значение заголовка больше 8 КиБ или всех заголовков больше 64 КиБ — загрузка завершается ошибкой.
- Поле, которого нет в ответе, отзывается; поля расхода остаются устаревшими ([«Время жизни метаданных»](README.md#metadata-lifetime)).
- Пустое значение `text` допустимо и заменяет сохранённое. Поля `url`, `integer` и `boolean` очистить нельзя.
- Метаданные читаются только из заголовков. Тело метаданных не несёт. Заголовок `reclash-*`, кроме `reclash-config`, игнорируется с предупреждением `Unsupported provider field` в «Инспекторе подписки».

## Форматы значений

| Тип | Синтаксис | Правила |
| --- | --- | --- |
| `text` | UTF-8, или `base64:` / `base64,` и Base64 от UTF-8 | Не больше 1024 байт после декодирования, если поле не указывает иное. Без управляющих символов; LF допустим в `announce`. |
| `url` | Абсолютный URL `http` или `https` | Нужен хост. Без userinfo, пробелов и управляющих символов. Не больше 1024 символов. |
| `integer` | Десятичное число | Умножается на масштаб синонима, затем проверяется диапазон. |
| `boolean` | `1`, `true`, `yes` / `0`, `false`, `no` | Без учёта регистра. |

## Subscription-Userinfo

```http
Subscription-Userinfo: upload=455727941; download=6174315083; total=107374182400; expire=1798761600
```

| Ключ | Значение |
| --- | --- |
| `upload`, `download` | Израсходованные байты. |
| `total` | Квота в байтах. `0` — без ограничения. |
| `expire` | Unix-время в секундах. `0` — бессрочно. |

Ключи не зависят от регистра и разделяются `;`. Значения — неотрицательные числа, дробная часть отбрасывается; `expire` не больше `8640000000000`. Повторённый ключ отбрасывается.

## Имя профиля

Профиль, которому пользователь не дал имя, получает первое доступное из:

1. имени файла из `Content-Disposition` (`filename*`, затем `filename`);
2. `profile-title` (text, 160 Б);
3. `provider.name` из [манифеста](manifest.md#provider);
4. хоста подписки.

Имя, заданное пользователем, никогда не заменяется. `profile-title` называет аккаунт, а не сервис.

## Интервал обновления

`profile-update-interval` задаёт интервал автообновления в часах. После пересчёта в минуты он должен быть в пределах 5–43200. Значение действует, только пока в редакторе профиля включён переключатель «Использовать интервал провайдера»; по умолчанию он выключен. Поля манифеста для него нет.

## Синонимы

Четыре стандартных заголовка заполняют поле [`provider` манифеста](manifest.md#provider), если манифест его не задаёт. Если манифест задаёт поле, он важнее.

| Заголовок | Поле манифеста | Тип |
| --- | --- | --- |
| `support-url` | `provider.support-url` | url |
| `profile-web-page-url` | `provider.web-url` | url |
| `announce` | `provider.announce` | text, многострочный, 1024 Б |
| `hide-url` | `provider.hide-url` | boolean |

## Указатель на манифест

```http
reclash-config: https://example.net/reclash.yaml
```

Единственный заголовок `reclash-*`, который читает ReClash. Это `url`, и он учитывается, только если пришёл в ответе по `https`. Правила доставки — в [«Доставке манифеста»](manifest.md#delivery). Другие клиенты его игнорируют.
