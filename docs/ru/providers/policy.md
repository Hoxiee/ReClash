# Обязательная политика безопасности

Версионированная секция `reclash-policy` в нативной подписке Clash: ограничивает трафик GLOBAL перечисленными узлами и держит перечисленные приложения Android вне VPN.

Политика — не профиль маршрутизации, не подсказка настроек и не правило, которое правит пользователь. Подписки без `reclash-policy` не затрагиваются. Схема: [`provider-policy.schema.json`](../../../provider-policy.schema.json).

## Структура

```yaml
reclash-policy:
  version: 1
  global:
    allow: [de-01]
  apps:
    android:
      exclude: [com.example.bank]
proxies:
  - name: Germany
    reclash-id: de-01
    type: socks5
    server: proxy.example.net
    port: 1080
  - name: Restricted
    reclash-id: restricted-01
    type: socks5
    server: restricted.example.net
    port: 1080
```

| Ключ | Тип | Правила |
| --- | --- | --- |
| `version` | integer | Должен быть `1`. |
| `global.allow` | список ID узлов | Без повторов, не больше 4096. |
| `apps.android.exclude` | список имён пакетов | Без повторов, не больше 512. |

Неизвестные ключи отклоняются на любом уровне.

## ID узлов

- `reclash-id` у элемента встроенного `proxies` даёт узлу имя для политики.
- Чувствителен к регистру, уникален в пределах подписки и соответствует `^[A-Za-z0-9][A-Za-z0-9._:-]{0,63}$`.
- Каждый ID из `global.allow` должен существовать.
- Разрешение привязано к полному определению маршрута узла, включая учётные данные, а не к имени. Переименование узла разрешение сохраняет; перенос ID на другой сервер — нет.

## Белый список GLOBAL

- Если секция `global` есть, по умолчанию всё запрещено: трафик GLOBAL могут нести только перечисленные ID. `allow: []` запрещает все узлы и убирает режим Global.
- Без `global` режим Global не ограничен, но ограничение [`noglobal`](app-settings.md#restrictions) всё равно его убирает.
- Участник из удалённого провайдера прокси запрещён, если его определение маршрута не совпадает с разрешённым встроенным узлом.
- Группа допустима для GLOBAL, только если разрешены все её возможные участники.
- Проверяется каждое соединение TCP и UDP, включая fallback, вложенный выбор, проверки доступности и изменения через контроллер.
- Запрещённый маршрут никогда не уходит в `DIRECT` или на неразрешённый узел.

## Исключения приложений Android

- `apps.android.exclude` обязателен, в отличие от рекомендуемого [`reclash-excludeapps`](app-settings.md#android-apps). Он сильнее приложений, которые пользователь вернул, включений белого списка и выключенного контроля доступа — в любом режиме маршрутизации.
- Обязательные записи заблокированы в «Контроле доступа» с меткой «Обязательно у провайдера».
- Они же закрывают локальные порты прокси, так что обойти их через локальный слушатель нельзя ([`androidsecure`](app-settings.md#restrictions)).
- Исключение — не блокировка интернета: исключённые приложения ходят через прямое подключение и с реальным IP. Заблокировать их может режим блокировки Android.

## Применение

Ядро читает политику из исходного профиля, а не из пользовательских скриптов, и хранит применённую политику вне `config.yaml`. Перезагрузка через контроллер и скрипты конфига не могут её снять. Смена режима или политики закрывает существующие соединения.

| Условие | Результат |
| --- | --- |
| Не Android или Android без режима VPN, а в политике есть исключения приложений | Отказ: `provider policy requires Android VPN app exclusions`. |
| Список приложений работающего VPN отличается от обязательных исключений | Отказ до перезапуска: `provider app exclusions are not applied; restart the VPN`. То же после переподключения к сервису с неизвестными параметрами. |
| Приложение соединения не удаётся определить | Блокировка: `provider policy could not identify this application`. |
| Исключённое приложение всё ещё захвачено старой сессией VPN | Блокировка: `provider policy requires this application to remain outside the VPN`. |
| Соединение GLOBAL через неразрешённый узел | Блокировка. Приложение предлагает выбрать разрешённый узел или режим Rule. |

Само приложение VPN исключить нельзя.

## Жизненный цикл

- Неизвестная версия или ключ, некорректный список, неизвестный или повторяющийся ID отклоняют весь импорт. Автоматический подбор не пробует другой пресет клиента.
- Неудачное обновление не меняет сохранённую подписку и её политику.
- Успешное обновление без `reclash-policy` отзывает политику; устаревшие метаданные её никогда не сохраняют.
- При переключении профиля применяется политика нового профиля.

## Ограничения

- Защищает от случайного использования в ReClash, который её соблюдает. Это не DRM и не гарантия на стороне сервера: другие клиенты эти поля игнорируют.
- Исключения пакетов не распространяются на тот же сервис, открытый в браузере.
- Версия 1 привязывает ID только во встроенном `proxies`.
