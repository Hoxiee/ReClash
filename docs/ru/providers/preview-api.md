# Preview API

Эндпоинт JSON только для чтения, версия 1: даёт оформление провайдера до того, как пользователь подтвердит импорт со страницы подписки в браузере.

Он отделён от загрузки подписки и от [заголовков ответа](headers.md), которые применяются к сохранённым профилям.

## Обнаружение

Страница подписки в браузере содержит ровно один элемент link:

```text
<link rel="reclash-preview" href="/reclash/preview/account-scoped-token">
```

- Относительный URL разрешается относительно итогового URL страницы.
- Эндпоинт должен иметь тот же origin (схему, хост и порт), что и страница, не должен совпадать с самой страницей и не должен содержать фрагмент.
- ReClash не перебирает типовые пути и не выполняет JavaScript, чтобы его найти.
- Для персонализации используйте в URL непрозрачный токен аккаунта. Не требуйте идентификатор устройства или вход в браузере.

## Запрос

- `GET` с `Accept: application/json` и `User-Agent` браузерного превью.
- Без идентификатора устройства, заголовков пресета клиента, cookies, `Authorization` и `Referer`.
- Редиректы проходят по правилам транспорта подписки. Принимается только итоговый JSON-ответ с того же origin.

## Ответ

`Content-Type: application/json`, не больше 64 КиБ JSON в UTF-8.

```json
{
  "version": 1,
  "provider": {
    "name": "Example VPN",
    "description": "Обратитесь в поддержку, чтобы установить подписку.",
    "logoUrl": "/assets/provider-logo.png",
    "supportUrl": "https://t.me/example_support"
  },
  "account": {
    "name": "Personal account"
  },
  "subscription": {
    "type": "test"
  }
}
```

| Поле | Тип | Правила |
| --- | --- | --- |
| `version` | integer | Обязательно, `1`. |
| `provider.name` | строка, 256 символов | Имя сервиса в заголовке подтверждения. |
| `provider.description` | строка, 4096 символов | Описание в теле подтверждения. |
| `provider.logoUrl` | URL | Абсолютный или относительно URL API; `http(s)`. Страница `https` не может ссылаться на `http`. PNG, JPEG, WebP, GIF, SVG или ICO, не больше 512 КиБ. При ошибке остаётся монограмма; внешние ресурсы SVG не загружаются. |
| `provider.supportUrl` | URL | `http(s)` или проверенная ссылка Telegram, относительно URL API. Показывается действием в верхней панели с обычным подтверждением внешней ссылки; никогда не открывается автоматически. |
| `account.name` | строка, 256 символов | Имя аккаунта, отдельно от провайдера и редактируемого имени профиля. |
| `subscription.type` | строка, 32 символа | `test`, `promo` или `dev` показывает значок под именем; для других значений значка нет. |

- Все поля, кроме `version`, необязательны. Неизвестные поля игнорируются.
- Текст — обычный текст, не HTML и не Markdown.
- Некорректное поле отбрасывается и не заменяет метаданные страницы.
- Неподдерживаемая версия, битый JSON, слишком большой ответ или ошибка запроса откатываются к метаданным страницы и никогда не блокируют импорт.
- Запрос логотипа не несёт cookies, `Authorization`, `Referer` и идентификатор устройства, даже на том же origin.
- Скрипты, стили, списки приложений, адреса телеметрии и URL конфигураций из JSON не выполняются и не открываются.

## Приоритет

Корректные поля API сильнее распознанного брендинга панели, а брендинг — сильнее общих HTML-метаданных. Отсутствующее поле API сохраняет значение с меньшим приоритетом.

## Требования к провайдеру

- Страница, эндпоинт и логотип должны быть безопасны для чтения до согласия. Они не должны регистрировать устройство, занимать слот устройства, отмечать конфигурацию загруженной или менять состояние аккаунта.
- Не кладите в ответ конфигурацию или ключи подключения.
- Отправляйте `Cache-Control: private, no-store` для ответов конкретного аккаунта. Не допускайте приватные токены в логи и публичные кеши.

ReClash не может обеспечить read-only поведение на стороне сервера. Только действие пользователя «Добавить» запускает загрузку подписки и любую идентификацию устройства. Данные превью только для показа: они не меняют настройки, маршрутизацию, идентичность транспорта, пресет клиента и сохранённый URL и не сохраняются как метаданные подписки. Тот же `subscription.type`, отправленный как [`reclash-subscriptiontype`](headers.md#provider-panel), отмечает сохранённый профиль.

## Существующие панели

Без этого API ReClash всё равно читает:

| Источник | Данные |
| --- | --- |
| Remnawave | Встроенные данные аккаунта и браузерные `brandingSettings`. Временная сессия страницы используется только для `/assets/.app-config-v2.json` на том же origin, никогда для этого API или логотипа. |
| 3x-ui | Встроенные данные страницы. |
| Marzban | Стандартные поля аккаунта. |
| Любая страница | Общие HTML-метаданные и явные ссылки на поддержку. |

Собственная тема панели подключается добавлением ссылки обнаружения; доставка подписки при этом не меняется.
