# Манифест провайдера

Манифест провайдера — один статический YAML-файл, который провайдер размещает один раз для всех пользователей и на который указывает заголовок ответа `reclash-config`. В нём всё, что ReClash показывает или применяет сверх стандартных заголовков: панель провайдера, напоминания, настройки, политика, приложения Android, транспорт, поддержка, оформление, карточки и маршрутизация. Тело подписки остаётся обычным mihomo.

## Быстрый старт

**1. Напишите `reclash.yaml`.**

```yaml
version: 1
provider:
  name: Пример VPN
  support-url: https://t.me/example_support
  web-url: https://example.net
  renew: { url: https://example.net/buy, days: 7 }
reminders:
  expire-days: [3, 1]
```

**2. Разместите файл и укажите на него.** Положите файл на любой статический HTTPS-хостинг и добавьте к подписке один заголовок ответа:

```http
reclash-config: https://example.net/reclash.yaml
```

**3. Проверьте.** Обновите профиль в ReClash и откройте «Профили» → меню профиля → «Инспектор подписки» ([«Инспектор подписки»](rollout.md#subscription-inspector)). Манифест применён, если инспектор не показывает предупреждений.

Любая секция необязательна. Добавляйте секции по мере необходимости; в полном примере ниже использованы все.

## Проверка в редакторе

Схема публикуется вместе с документацией. Поставьте этот комментарий первой строкой, и редакторы с языковым сервером YAML будут проверять файл и подсказывать ключи:

```yaml
# yaml-language-server: $schema=https://reclash.pages.dev/schemas/provider-config.schema.json
version: 1
```

В CI:

```sh
uvx check-jsonschema --schemafile https://reclash.pages.dev/schemas/provider-config.schema.json reclash.yaml
```

Схема строже приложения: приложение игнорирует неизвестный ключ с предупреждением, схема его отклоняет. Исходник — [`provider-config.schema.json`](../../../provider-config.schema.json).

## Доставка

- `reclash-config: <https url>` учитывается, только если пришёл в ответе по `https`. Редирект должен заканчиваться на URL с `https`.
- Файл — не больше 512 КиБ. Профиль или сценарий внутри него — не больше 64 КиБ. `ETag` и `304 Not Modified` поддерживаются.
- Он загружается вместе с обновлением подписки и укладывается в 8 секунд (меньше, если на обновление осталось меньше времени).
- Манифест на origin подписки получает заголовки запроса подписки. Другой origin получает только `User-Agent`, `Accept` и `Accept-Language`; идентификатор устройства не покидает origin подписки.
- Сохранённая копия заменяется целиком, после полной проверки. Неудачная или некорректная загрузка сохраняет последнюю корректную копию и никогда не проваливает обновление.
- Пропуск `reclash-config` удаляет сохранённую копию. Секция, которой нет в новой корректной копии, отзывается ([«Владение»](#ownership)).
- Копия хранится рядом с профилем, и ядро читает из неё `routing`. Резервные копии её не содержат: после восстановления секции отсутствуют до следующего обновления.
- Предупреждения загрузки и проверки показывает [«Инспектор подписки»](rollout.md#subscription-inspector).

## Формат

- `version: 1` обязателен. Любое другое значение отклоняет файл.
- Ключи — в kebab-case. Якоря, алиасы, повторяющиеся ключи, нестроковые ключи и вложенность глубже 32 уровней отклоняют файл.
- Типы строгие, без приведения: `"12"` — не число, `"true"` — не булево значение, строка — не список, а список — не строка.
- Неизвестный ключ даёт предупреждение и игнорируется. Неизвестное значение перечисления в `view` или `power-button` игнорируется.
- Все URL — только `https`, если поле не говорит иного.
- Некорректная карточка пропускается отдельно, с предупреждением. Некорректная секция игнорируется целиком, с предупреждением, а её значения отзываются. К заголовку возвращаются только четыре поля `provider` с синонимами ([«Провайдер»](#provider)).

> [!WARNING]
> Цвета берите в кавычки: `color: #336699` — это комментарий YAML. Значение становится пустым, а ключ игнорируется с предупреждением.

> [!TIP]
> Ключи `on` и `off` в `power-labels` берите в кавычки. Инструменты YAML 1.1 читают их как булевы значения.

### Локализованный текст

Каждый `name`, `text`, `title`, `label` и `hint` — обычная строка или словарь локалей. Клиент берёт точный тег (`pt-br`), затем язык (`pt`), затем `en`, затем первую запись. Регистр тегов не важен. Словарь с пустой или нестроковой записью недопустим.

```yaml
cards:
  - id: welcome
    type: note
    text:
      en: Welcome back.
      pt-BR: Bem-vindo de volta.
      ru: С возвращением.
```

## Владение

- Значения провайдера применяются без подтверждения, пока их профиль текущий, и помечены «От провайдера».
- Настройка, которую изменил пользователь, перестаёт следовать провайдеру; её метка предлагает «Вернуть провайдеру».
- «Вернуть настройки провайдеру» в настройках приложения сбрасывает все настройки, переопределения пользователем общих параметров, DNS и TUN, а также его изменения в приложениях провайдера.
- Когда текущий профиль перестаёт задавать значение, например после переключения на другой профиль, настройка, которая ещё следует провайдеру, возвращается к прежнему значению пользователя.
- Пропуск секции или ключа в ней отзывает значение ([«Время жизни метаданных»](README.md#metadata-lifetime)).
- Только [`policy`](#policy) задаёт ограничения, которые пользователь не может снять.

## Секции

### Провайдер

`provider` описывает сервис. Текстовые поля принимают обычную строку или словарь локалей; лимиты — в символах.

| Ключ | Тип | Где показывается |
| --- | --- | --- |
| `name` | text, 160 | Имя сервиса на карточке дашборда и в окне импорта. |
| `logo` | url | Логотип на простом дашборде. |
| `logo-dark` | url | Логотип в тёмной теме. Если не задан, берётся `logo`. |
| `support-url` | url | Действие «Поддержка». Принимает также `https://t.me/…`, `https://telegram.me/…` и ссылки `tg://`, например `tg://resolve?domain=…`. |
| `web-url` | url | Действие «Сайт». |
| `type` | text, 32 | Значок в окне импорта и списке профилей: `test`, `promo` или `dev`. Другие значения значка не дают. |
| `hide-url` | boolean | Скрывает URL в редакторе профиля и окне импорта. Секретным URL он не делает. |
| `server-group` | text, 256 | Группа прокси, выбранный узел которой показывает простой дашборд. Сравнивается без учёта регистра. |
| `announce` | `{text, url}` | Описание. `text` многострочный, 1024. Показывается в окне импорта и в карточке дашборда над виджетами, которую пользователь не может ни переместить, ни убрать. `url` — ссылка в карточке. |
| `notice` | `{text, url}` | Закрываемое уведомление на дашборде. `text` многострочный, 1024. Закрытие запоминается для этого текста и ссылки; при их изменении уведомление появится снова. |
| `renew` | `{url, days}` | Действие продления, предлагается начиная с `days` до конца срока (1–3650). |
| `top-up` | `{url, percent}` | Действие докупки трафика, предлагается начиная с `percent` израсходованной квоты (1–100). |

Значение `days` или `percent` вне диапазона отбрасывается с предупреждением; `url` применяется. Чтобы убрать сообщение, уберите его ключ.

Четыре поля при отсутствии в манифесте берутся из стандартного заголовка: `support-url`, `web-url` (`profile-web-page-url`), `announce` и `hide-url` ([«Синонимы»](headers.md#aliases)). Если манифест задаёт поле, он важнее. Если вся секция `provider` некорректна, эти четыре поля всё равно берутся из заголовков.

```yaml
provider:
  notice:
    text: |
      Технические работы 1 ноября, 02:00–03:00 UTC.
      Подключение может прерываться.
    url: https://status.example.net
```

### Напоминания

`reminders` задаёт, когда ReClash напоминает о сроке и трафике.

| Ключ | Значение | Действие |
| --- | --- | --- |
| `expire-days` | Целые 0–365, не больше 8 | За сколько дней до конца срока приходит уведомление. По умолчанию `[3, 2, 1]`. |
| `traffic-percent` | Целые 1–100, не больше 8 | Процент израсходованной квоты, при котором приходит уведомление. По умолчанию `[90]`. |

- Напоминаниям нужен `Subscription-Userinfo`. Напоминания о сроке не приходят при `expire=0`, о трафике — при `total=0`, а пока поле расхода устарело, не приходит ни одно.
- Каждый порог срабатывает один раз на дату окончания. Порог трафика снова взводится, когда расход опускается ниже него.
- Действие уведомления о трафике — докупка (если `top-up.percent` не задан или достигнут), иначе продление (если `renew.days` не заданы или достигнуты), иначе поддержка.
- На дашборде продление появляется начиная с `renew.days` до конца срока или, если `days` не заданы, с наибольшего порога срока. Докупка появляется начиная с `top-up.percent` израсходованной квоты или, если он не задан, с наименьшего порога трафика.

```yaml
reminders:
  expire-days: [7, 3, 1]
  traffic-percent: [80, 95]
```

### Настройки

`settings` задаёт настройки приложения. Затрагиваются только перечисленные ключи: `true` включает настройку, `false` явно выключает, а неперечисленный ключ сохраняет значение пользователя.

| Ключ | Настройка | Действие |
| --- | --- | --- |
| `minimize-on-exit` | «Сворачивать при выходе» | Закрытие окна сворачивает приложение. |
| `launch-at-login` | «Автозапуск» | Запускает приложение при входе в систему. |
| `start-hidden` | «Тихий запуск» | Запускает приложение без показа окна. |
| `connect-on-launch` | «Автовключение» | Включает прокси при открытии приложения. |
| `check-app-updates` | «Автопроверка обновлений» | Проверяет обновления приложения. |
| `capture-logs` | «Захват логов» | Собирает логи. Выключение скрывает пункт логов. |
| `close-connections` | «Закрыть соединения» | Разрывает открытые соединения при смене прокси. |

```yaml
settings:
  connect-on-launch: true
  close-connections: true
```

### Политика

`policy` задаёт ограничения, которые пользователь не может снять. Каждый ключ необязателен; по умолчанию пользователь свободен. Подробности и часть каждого ограничения в теле подписки — в [«Политике безопасности»](policy.md).

| Ключ | Значения | Действие |
| --- | --- | --- |
| `global` | `any` (по умолчанию), `listed`, `off` | `listed` ограничивает трафик GLOBAL узлами группы `GLOBAL` из тела ([подробнее](policy.md#only-listed-nodes-in-global)). `off` убирает режим Global в приложении и ядре; профиль в Global переключается на Rule ([подробнее](policy.md#no-global)). |
| `apps` | `recommended` (по умолчанию), `required` | `required` делает `tun.exclude-package` обязательным на Android ([подробнее](policy.md#apps-that-must-stay-outside-the-vpn)). |
| `local-ports` | `open` (по умолчанию), `closed` | Только Android. `closed` закрывает все локальные порты прокси (mixed, HTTP, SOCKS, redir, TProxy), делает веб-панель недоступной и отправляет собственные запросы приложения напрямую. Действует и при `apps: required` ([подробнее](policy.md#no-local-proxy-ports)). |
| `dashboard` | `editable` (по умолчанию), `locked` | `locked` убирает редактирование обоих дашбордов ([подробнее](policy.md#locked-dashboard)). |

Некорректное значение отзывает всю секцию `policy` с предупреждением.

```yaml
policy:
  global: off
  dashboard: locked
```

### Приложения

`apps` предлагает списки приложений Android. Это рекомендации: пользователь может их забрать. Чтобы сделать исключения обязательными, задайте [`policy.apps: required`](policy.md#apps-that-must-stay-outside-the-vpn).

| Ключ | Действие |
| --- | --- |
| `exclude` | Рекомендуемые исключения из туннеля, вместе с `tun.exclude-package` в конфиге. |
| `include` | Рекомендуемые включения, вместе с `tun.include-package` в конфиге. |
| `routing` | `domestic` или `domestic:<cc>`. Добавляет установленные приложения, которые приложение знает как местные для региона приложения или для `<cc>`. Игнорируется, если для региона нет списка. |

`exclude` и `include` — списки имён пакетов Android: не больше 255 символов на имя, а больше 512 имён делают поле некорректным. Некорректное имя отбрасывается отдельно, с предупреждением.

Как они сочетаются с «Контролем доступа» пользователя:

| Контроль доступа | Что добавляет провайдер |
| --- | --- |
| Выключен | Рекомендуемые и обязательные исключения, если они есть, включают режим чёрного списка только с этими приложениями. |
| Чёрный список | Рекомендуемые исключения, которые пользователь не забрал, и обязательные исключения добавляются к списку пользователя. |
| Белый список | Рекомендуемые включения, которые пользователь не забрал, добавляются к списку пользователя. Обязательные исключения из него убираются. |

Режимы не смешиваются: рекомендуемые включения игнорируются в режиме чёрного списка, а рекомендуемые исключения — в режиме белого. Приложения провайдера отмечены меткой «От провайдера» в «Контроле доступа». Снятая галочка забирает приложение обратно; «Вернуть приложения провайдеру» сбрасывает это. Когда действующий список меняется, Android просит перезапустить VPN.

```yaml
apps:
  exclude: [com.example.bank, ru.example.gov]
  routing: domestic
```

### Транспорт

`transport` называет другие хосты подписки. Работает только для подписок `https` ([«Резервные хосты»](request.md#fallback-hosts)).

| Ключ | Значение |
| --- | --- |
| `fallback-hosts` | Список до 5 `host[:port]`. Приводятся к нижнему регистру; префикс `https://` и завершающий `/` отбрасываются. Одна некорректная запись делает поле некорректным. |
| `new-domain` | Один `host[:port]` строкой, не списком. |

```yaml
transport:
  fallback-hosts: [sub2.example.net, sub3.example.org:8443]
  new-domain: sub.example.com
```

### Поддержка

`support` включает подписанные ссылки-исправления и прямую отправку отчётов ([«Отчёты поддержки»](support.md)).

| Ключ | Значение |
| --- | --- |
| `keys` | Не больше двух открытых ключей `ed25519:…` для [подписанных ссылок-исправлений](support.md#key). |
| `upload-url` | URL `https`, принимающий [отчёты поддержки](support.md#receiving-reports). |

Оба заменяются при каждом обновлении. Им нужно согласие: перед первой отправкой приложение называет домен загрузки.

```yaml
support:
  keys: ["ed25519:O2onvM62pC1io6jQKm8Nc2UyFXcd4kOmOsBIoYtZ2ik"]
  upload-url: https://support.example.net/reclash/reports
```

### Вид

`view` задаёт внешний вид списка прокси и приложения. Содержит группы `proxies` и `app`; неизвестные ключи и значения игнорируются.

| Ключ | Значения |
| --- | --- |
| `proxies.type` | `tab`, `list` |
| `proxies.sort` | `none`, `delay`, `name` |
| `proxies.layout` | `loose`, `standard`, `tight` |
| `proxies.icon` | `filled`, `plain`, `hidden` |
| `proxies.card` | `loose`, `standard`, `compact`, `oneline` |
| `app.navbar` | `floating`, `docked` |
| `app.tabs` | `slide`, `fade` |
| `app.glass` | `none`, `standard`, `ultra` |
| `app.color` | `RRGGBB` или `AARRGGBB` в кавычках, `#` необязателен |
| `app.color-dark` | Как `app.color`. Заменяет его в тёмной теме; без `app.color` игнорируется. |
| `app.style` | `vivid`, `tinted`, `soft`, `monochrome` |
| `app.black` | Булево значение |

`app.glass` задаёт желаемое качество. При устойчивой перегрузке отрисовки фактическое качество может снизиться на текущую сессию без изменения сохранённой настройки и её принадлежности провайдеру; уведомление предлагает вернуть его.

`view`, `power-button`, `wallpaper` и `widgets` — единственный источник оформления; заголовка для него нет. Значения помечаются «От провайдера» и уступают пользователю ([«Владение»](#ownership)).

```yaml
view:
  app:
    color: "#336699"
    style: tinted
  proxies:
    type: list
    sort: delay
```

### Кнопка питания

`power-button` оформляет работающую кнопку питания простого дашборда. У пользователя такой настройки нет.

| Ключ | Значения | По умолчанию |
| --- | --- | --- |
| `shape` | Одно имя формы, список имён или `random` | `cookie` |
| `type` | `solid`, `tonal`, `outline` | `solid` |

Формы: `cookie`, `circle`, `scallop`, `sunny`, `flower`, `clover`, `burst`, `puffy`, `puffyDiamond`, `clover8Leaf`, `cookie4Sided`, `cookie6Sided`, `verySunny`, `square`, `diamond`, `pentagon`, `gem`, `pixelCircle`, `softBoom`, `boom`, `sharpBurst`.

- Имена не зависят от регистра. Неизвестные формы игнорируются, дубликаты не повышают шанс формы. Если нет ни одной известной формы, кнопка — `cookie`.
- `random` означает все формы и действует, только если это всё значение.
- Список — это пул: форма выбирается равновероятно и держится до конца сессии приложения, пока не поменяется профиль или набор допустимых форм.

```yaml
power-button:
  shape: [puffy, clover8Leaf]
  type: outline
```

### Обои

`wallpaper` задаёт фоновое изображение приложения.

| Ключ | Значения | По умолчанию |
| --- | --- | --- |
| `url` | URL изображения по `https`. Обязателен: без него секция недопустима. | — |
| `opacity` | Целое 1–100 | 8 |

Изображение загружается один раз на URL и кешируется.

```yaml
wallpaper:
  url: https://cdn.example.net/wallpaper.webp
  opacity: 12
```

### Виджеты

`widgets` — список карточек дашборда в порядке показа.

Токены: `currentOutbound`, `health`, `networkSpeed`, `outboundMode`, `vpnButton` (Android), `networkTakeover` (десктоп), `serviceStatus`, `profiles`, `proxyGroups`, `connectionStats`, `intranetIp`, `memoryInfo`.

- Токены не зависят от регистра. Неизвестные игнорируются; значение без известных токенов оставляет дашборд без изменений.
- `currentOutbound` добавляется первым, если его нет.
- Простой дашборд использует перечисленные `outboundMode`, `serviceStatus` и `health`; если ни один не указан, он не меняется.
- `provider.announce` — не виджет: его карточка показывается над виджетами, пока оно задано, и её нельзя перечислить, переместить или убрать.

```yaml
widgets: [outboundMode, serviceStatus, health]
```

### Карточки

`cards` — список не больше чем из 8 карточек, они показываются над виджетами в порядке файла. Карточки после восьмой отбрасываются с предупреждением. У каждой карточки есть общие ключи:

| Ключ | Значения |
| --- | --- |
| `id` | Обязателен. Уникальный, по шаблону `[a-z0-9._:#-]{1,64}`. |
| `type` | Обязателен: `banner`, `note`, `actions`. |
| `when` | Необязательное [условие](#conditions). |
| `dismissible` | Булево значение, по умолчанию `false`. Скрытие запоминается для точного содержимого карточки; после изменения карточка показывается снова. |

Ключ, которого нет у типа карточки, даёт предупреждение и игнорируется. Лимиты: `title` — 80 символов, `text` — 280, `label` — 32; значение `copy` — не больше 256 байт, `share` — не больше 1024 байт.

#### Действия

Карточка, кнопка и элемент `actions` несут не больше одного ключа действия. Несколько ключей или некорректное значение делают карточку недопустимой.

| Ключ | Эффект |
| --- | --- |
| `url` | Открывает ссылку `http`, `https` или Telegram, не длиннее 2048 символов. |
| `copy` | Копирует текст. |
| `share` | Открывает системное меню «Поделиться» на Android; на остальных платформах копирует текст. |
| `app` | Запускает фиксированное действие приложения. |

Значения `app`:

| Значение | Эффект | Скрыто, если |
| --- | --- | --- |
| `support` | Открывает ссылку поддержки провайдера. | Нет корректного `provider.support-url`. |
| `website` | Открывает страницу провайдера. | Нет корректного `provider.web-url`. |
| `renew` | Открывает ссылку покупки тарифа. | Нет корректного `provider.renew`. |
| `topUp` | Открывает ссылку покупки трафика. | Нет корректного `provider.top-up`. |
| `updateProfile` | Обновляет текущий профиль. | — |
| `speedTest` | Открывает тест скорости. | — |
| `doctor` | Открывает Doctor. | — |
| `updateApp` | Открывает окно обновления. | — |

Скрытое действие убирает свой элемент `actions`, а действие всей карточки перестаёт быть нажимаемым. Ни одно действие не меняет настройки, не импортирует подписку и не запускает и не останавливает соединение.

#### Баннер

| Ключ | Значения |
| --- | --- |
| `layout` | `hero` (по умолчанию), `split`, `strip`, `image` |
| `title`, `text` | Локализованный текст |
| `image`, `image-dark` | URL изображения по `https`. `image-dark` используется в тёмной теме. |
| `side` | `start`, `end` (по умолчанию). Сторона изображения в `split`. |
| `tone` | `surface` (по умолчанию), `primary`, `secondary`, `tertiary` |
| `countdown` | Unix-время в секундах. Показывает время до него. |
| `button` | `{label, <действие>}`. Карточка с кнопкой сама не нажимается. |
| `url`, `copy`, `share`, `app` | Действие всей карточки. |

Баннер `image` — это одно изображение, и оно обязательно.

```yaml
cards:
  - id: strip
    type: banner
    layout: strip
    tone: tertiary
    text: Сегодня в 02:00 UTC технические работы.
    url: https://status.example.net
```

#### Заметка

| Ключ | Значения |
| --- | --- |
| `text` | Обязателен, локализованный |
| `level` | `info` (по умолчанию), `warning`, `critical` |
| `url`, `copy`, `share`, `app` | Действие всей карточки |

```yaml
cards:
  - id: low-traffic
    type: note
    level: warning
    text: Трафик почти закончился.
    app: topUp
```

#### Карточка действий

`items` — список из 2–6 элементов.

| Ключ | Значения |
| --- | --- |
| `icon` | Обязательное имя. |
| `label` | Обязателен, локализованный |
| `url`, `copy`, `share`, `app` | Ровно один |

Значки: `support`, `help`, `chat`, `speed`, `link`, `open`, `copy`, `share`, `refresh`, `update`, `sync`, `info`, `warning`, `star`, `bolt`, `key`, `lock`, `gift`, `sparkle`, `web`, `website`, `globe`, `send`, `telegram`, `download`, `doctor`, `tools`, `clock`, `renew`, `account`. Неизвестное имя показывает нейтральный значок.

```yaml
cards:
  - id: help
    type: actions
    items:
      - { icon: support, label: Поддержка, app: support }
      - { icon: telegram, label: Канал, url: "https://t.me/example" }
```

### Условия

`when` показывает карточку, только пока выполнены все перечисленные ключи. Без `when` карточка показывается всегда.

| Ключ | Выполнено, когда |
| --- | --- |
| `from` | Сейчас не раньше этого Unix-времени. |
| `until` | Сейчас раньше этого Unix-времени. |
| `days-left-below` | У подписки есть срок действия и осталось меньше полных дней. |
| `traffic-above` | Использованная доля ненулевого объёма не меньше этого процента. |
| `platforms` | Платформа есть в списке: `android`, `windows`, `macos`, `linux`. |
| `client-below` | Версия приложения ниже этой версии. |

- Условия по расходу никогда не выполняются на устаревших данных о расходе.
- `client-below` достигает только клиентов, которые поддерживают эту возможность: старые клиенты файл не читают.
- Время срабатывает само, пока приложение открыто.

```yaml
cards:
  - id: update-hint
    type: note
    text: Вышла новая версия приложения.
    app: updateApp
    when:
      client-below: 1.5.0
      platforms: [android]
```

### Подписи кнопки питания

`power-labels` заменяет заголовок под кнопкой питания. Состояния: `off`, `connecting`, `on`, `paused` и для тарифа: `expired` (тариф закончился, с подключением или без), `exhausted` (закончился трафик), `ending` (тариф скоро закончится по порогам `reminder`), `grace` (подключено на закончившемся тарифе). Проблемы, которые приложение нашло само, например нет сети или связь не работает, всегда оставляют заголовок приложения. Каждое состояние принимает одно из:

- строку или словарь локалей,
- `{title, hint}`, где каждая часть может быть словарём локалей,
- список таких значений: на сессию приложения выбирается одно.

| Часть | Лимит |
| --- | --- |
| `title` | 64 символа |
| `hint` | 96 символов |

Записи вне лимитов отбрасываются; если в состоянии ничего не осталось, используется локализованная подпись.

Подстановки: `{daysLeft}`, `{trafficLeft}`, `{server}`. Если у подстановки нет значения, вся запись заменяется локализованной подписью. `hint` показывается только там, где под заголовком нет действия кнопки: не у `on`, где остаётся живая строка соединения, и не рядом с кнопкой «Продлить» или «Докупить». Подписи никогда не меняют смысл, цвет или форму кнопки.

```yaml
power-labels:
  connecting:
    en: Connecting to {server}
    ru: Подключение к {server}
  paused:
    title: Пауза
    hint: Нажмите, чтобы продолжить
```

### Маршрутизация

`routing` предлагает профили и сценарии автомаршрутизации. Их синтаксис описан в [«Профилях»](../auto-routing/profiles.md) и [«Сценариях»](../auto-routing/scenarios.md). В теле подписки ключей маршрутизации нет, поэтому оно остаётся корректным для других клиентов Clash.

| Ключ | Значение |
| --- | --- |
| `profiles` | Словарь «имя профиля → профиль». |
| `scenarios` | Словарь «имя сценария → сценарий». |
| `scenario` | Имя сценария по умолчанию. |
| `bindings` | Словарь «имя группы прокси → привязка», см. ниже. |

Профиль адресуется как `provider/<имя>`. `extends` может ссылаться на `builtin/<имя>` или на другой профиль провайдера.

```yaml
routing:
  profiles:
    fast-de:
      rcx: 1
      title: Fast Germany
      prefer:
        - { label: Germany, when: 'country = DE' }
        - { label: Anything, when: 'not dead' }
  bindings:
    Proxy: { profiles: [fast-de], default: fast-de }
```

#### Привязка группы

| Ключ | Значение |
| --- | --- |
| `profiles` | Имена профилей, предложенных для группы. |
| `default` | Профиль, который действует, пока пользователь не выбрал свой. |
| `chips` | До 12 пулов в одно касание: `{label, include}`, где `include` — [условие](../auto-routing/conditions.md). |
| `pool` | Условия `{include, exclude}`, сужающие серверы группы. |
| `prefer` | Порядок серверов, заменяющий порядок профиля для этой группы. `prefer` программы сценария сильнее. |
| `feel` | Характер переключения: `calm`, `balanced` или `eager` ([«Как работает движок»](../auto-routing/engine.md)). |
| `energy` | Бюджет проверок: `eco`, `balanced` или `precise`. |

Привязка адресует группу по имени. Привязка к группе, которой нет в конфиге, даёт предупреждение в «Инспекторе подписки», а группа, переименованная в теле, молча теряет привязку, пока манифест не обновлён.

#### Ограничения провайдера

| Ограничение | Правило |
| --- | --- |
| Пул | Привязка провайдера может только сузить пул группы. |
| `direct-split` | От провайдера игнорируется; включить его может только пользователь. |
| Размер | Профиль или сценарий — не больше 64 КиБ. |
| Сторонние хосты | Профилю или сценарию, чьи проверки, диагностика или echo-сервисы обращаются к хосту вне сайта провайдера, нужно согласие пользователя. Сайт провайдера — регистрируемый домен хоста подписки; адреса встроенных профилей разрешены всегда. До согласия группа работает на `builtin/simple`. |
| Выбор | Профили и сценарии — это предложения: пользователь выбирает профиль для каждой группы и сценарий или выключает автоуправление. |

#### Проверка

```sh
dart run tool/rcx.dart lint reclash.yaml
```

Линтер принимает профиль, сценарий, документ с `profiles` или `scenarios` либо манифест с `routing`. В приложении ядро показывает некорректный или отсутствующий профиль провайдера как проблему в статусе группы или сценария.

## Изображения

- `image` и `image-dark` — только `https`: PNG, JPEG или WebP, не больше 2 МиБ. SVG не поддерживается.
- Изображения кешируются на сутки. Неудачное обновление сохраняет кешированную копию.
- Баннер с неудачным изображением показывает свой текст. Баннер `image` без рабочего изображения не показывает ничего.

> [!NOTE]
> Запрос изображения раскрывает IP-адрес пользователя хосту изображения, а URL для одного пользователя идентифицирует зрителя. Собственной телеметрии клиент не отправляет.

## Границы

- Провайдер может задать только настройки с этой страницы, [интервал обновления](headers.md#update-interval) и предложения маршрутизации из [«Маршрутизации»](#routing).
- Ни одно поле манифеста само не запускает отчёты, телеметрию или выгрузку данных.
- `provider.hide-url` скрывает URL, но не защищает его.
- Исключения пакетов не распространяются на тот же сервис, открытый в браузере.
