# Настройки приложения

Оформление, флаги настроек, ограничения и списки приложений Android, которые может задать подписка, и то, как они уступают пользователю.

Синтаксис значений — по [«Форматам значений»](headers.md#value-formats). Подсказки берутся из текущего профиля. Оформление приходит только из [размещённого конфига](config.md); заголовка для него нет.

## Владение

- Значения провайдера применяются без подтверждения, пока их профиль текущий, и помечены «От провайдера».
- Изменённая настройка перестаёт следовать провайдеру; её метка предлагает «Вернуть провайдеру».
- «Вернуть настройки провайдеру» в настройках приложения сбрасывает все настройки. Заодно сбрасываются переопределения пользователем общих параметров, DNS и TUN из подписки и его изменения в приложениях провайдера.
- Когда текущий профиль перестаёт задавать значение, например после переключения на другой профиль, настройка, которая ещё следует провайдеру, возвращается к прежнему значению пользователя.
- Пропуск заголовка или секции конфига отзывает значение: настройка возвращается к значению пользователя ([«Время жизни метаданных»](README.md#metadata-lifetime)).

## Оформление

Вид, кнопка питания, обои и виджеты задаются в [размещённом конфиге](config.md#sections), на который ссылается `reclash-config`. Их значения подчиняются правилам владения выше.

## Флаги настроек

`reclash-settings` перечисляет флаги как `tokens`, не больше 16. Перечисленные флаги включаются, остальные выключаются. Без заголовка ни одна из этих настроек не затрагивается.

| Флаг | Настройка | Действие |
| --- | --- | --- |
| `minimize` | «Сворачивать при выходе» | Закрытие окна сворачивает приложение. |
| `autorun` | «Автозапуск» | Запускает приложение при входе в систему. |
| `shadowstart` | «Тихий запуск» | Запускает приложение без показа окна. |
| `autostart` | «Автовключение» | Включает прокси при открытии приложения. |
| `autoupdate` | «Автопроверка обновлений» | Проверяет обновления приложения. |
| `openlogs` | «Захват логов» | Собирает логи. Выключение скрывает пункт логов. |
| `closeconnections` | «Закрыть соединения» | Разрывает открытые соединения при смене прокси. |

```http
reclash-settings: autostart,closeconnections
```

## Ограничения

`reclash-restrictions` перечисляет ограничения как `tokens`, не больше 16. Пользователь не может их снять.

| Токен | Действие |
| --- | --- |
| `noglobal` | Убирает режим Global в приложении и ядре. Профиль в Global переключается на Rule. |
| `androidsecure` | Только Android. Закрывает все локальные порты прокси (mixed, HTTP, SOCKS, redir, TProxy), делает веб-панель недоступной и отправляет собственные запросы приложения напрямую. |
| `denywidgets` | Убирает редактирование обоих дашбордов. |

`androidsecure` действует и тогда, когда [политика безопасности](policy.md) требует исключений приложений. Политика с `global.allow: []` убирает Global так же, как `noglobal`.

## Приложения Android

| Источник | Действие |
| --- | --- |
| `reclash-excludeapps`, `tun.exclude-package` в конфиге | Рекомендуемые исключения из туннеля. |
| `reclash-approuting: domestic` или `domestic:<cc>` | Добавляет установленные приложения, которые приложение знает как местные для региона приложения или для `<cc>`. Игнорируется, если для региона нет списка. |
| `reclash-includeapps`, `tun.include-package` в конфиге | Рекомендуемые включения. |
| `reclash-policy` → `apps.android.exclude` | Обязательные исключения ([«Обязательная политика безопасности»](policy.md)). |

Как они сочетаются с «Контролем доступа» пользователя:

| Контроль доступа | Что добавляет провайдер |
| --- | --- |
| Выключен | Рекомендуемые и обязательные исключения, если они есть, включают режим чёрного списка только с этими приложениями. |
| Чёрный список | Рекомендуемые исключения, которые пользователь не забрал, и обязательные исключения добавляются к списку пользователя. |
| Белый список | Рекомендуемые включения, которые пользователь не забрал, добавляются к списку пользователя. Обязательные исключения из него убираются. |

Режимы не смешиваются: рекомендуемые включения игнорируются в режиме чёрного списка, а рекомендуемые исключения — в режиме белого. Приложения провайдера отмечены меткой «От провайдера» в «Контроле доступа». Снятая галочка забирает приложение обратно; «Вернуть приложения провайдеру» сбрасывает это. Когда действующий список меняется, Android просит перезапустить VPN.

```http
reclash-excludeapps: com.example.bank, ru.example.gov
reclash-approuting: domestic
```

## Границы

- Провайдер может задать только настройки с этой страницы, [интервал обновления](headers.md#update-interval) и предложения маршрутизации из [«Доставки маршрутизации»](routing.md).
- Ни один заголовок не запускает отчёты, телеметрию или выгрузку данных.
- `reclash-hideurl` скрывает URL, но не защищает его.
- Исключения пакетов не распространяются на тот же сервис, открытый в браузере.
