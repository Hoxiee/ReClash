# Интеграция провайдера

Как провайдер подписки передаёт ReClash конфигурацию, метаданные, маршрутизацию и политику. Начните отсюда, затем откройте страницу нужной области.

## Модель

Подписка — это один HTTP GET. Тело несёт конфигурацию, заголовки — метаданные.

| Канал | Что несёт | Справочник |
| --- | --- | --- |
| Тело | YAML конфига mihomo (Clash). Ссылки, Xray, sing-box, WireGuard и Amnezia конвертируются при импорте и могут терять данные. Тела, зашифрованные AGE, сначала расшифровываются. | — |
| Заголовки ответа | Аккаунт, панель, оформление, напоминания, транспорт и подсказки приложению. | [«Заголовки ответа»](headers.md) |
| Комментарии в теле | Те же метаданные строками `#имя: значение` в начале тела — для хостинга, где нельзя задать заголовки. | [«Комментарии в теле»](headers.md#body-comments) |
| Ключи тела | `rcx-profiles`, `rcx-scenarios`, `rcx-scenario`, ключ группы `rcx`, `reclash-policy`. Обычный mihomo их игнорирует. | [«Доставка маршрутизации»](routing.md), [«Обязательная политика безопасности»](policy.md) |
| Бандл маршрутизации | Отдельный YAML, на который ссылается `reclash-routing`. | [«Бандл маршрутизации»](routing.md#routing-bundle) |
| Эндпоинт превью | JSON, который показывается до подтверждения импорта из браузера. | [«Preview API»](preview-api.md) |

## Цикл загрузки

1. Отправляет запрос с пресетом клиента профиля и, если включён, с идентификатором устройства ([«Заголовки запроса»](request.md)).
2. Проходит до 5 редиректов и декодирует тело ([«Редиректы и транспорт»](request.md#redirects-and-transport)).
3. Декодирует заголовки и комментарии в теле по [реестру](standard.md). Некорректные значения отбрасываются с предупреждением.
4. Сливает результат с сохранёнными метаданными ([«Время жизни метаданных»](#metadata-lifetime)).
5. Загружает бандл маршрутизации, если он указан.
6. Применяет конфигурацию, подсказки и политику.

Обновление отклоняется, а сохранённый профиль не меняется, если тело пустое, его формат не распознан или в нём нет ни узлов, ни групп, ни удалённых провайдеров.

## Уровни доверия

| Уровень | Действие | Примеры |
| --- | --- | --- |
| `display` | Показывается пользователю. Поведение не меняет. | `reclash-servicename`, `reclash-announce`, `reclash-hideurl` |
| `hint` | Меняет поведение в заданных рамках. | `reclash-autoupdateinterval`, `reclash-view`, `reclash-excludeapps` |

Реестр также определяет уровень `consent`, который пока не использует ни одно поле. Большинство подсказок уступает изменениям пользователя ([«Владение»](app-settings.md#ownership)). Только [`reclash-restrictions`](app-settings.md#restrictions) и [обязательная политика безопасности](policy.md) задают ограничения, которые пользователь не может снять.

## Время жизни метаданных

Каждое успешное обновление накладывает новые поля поверх сохранённых:

- Поле из ответа заменяет сохранённое значение.
- Отсутствующее поле расхода (`Subscription-Userinfo`, `subscription.*`) сохраняет последнее значение и помечается устаревшим. Пока оно устарело, напоминания о сроке и трафике не приходят.
- Любое другое отсутствующее поле отзывается. Настройка, которая следовала за ним, возвращается к значению пользователя.
- Неудачное обновление ничего не меняет.

[«Инспектор подписки»](rollout.md#subscription-inspector) показывает устаревшие поля и предупреждения.

## Версия стандарта

Реестр — стандарт версии 1. [«Реестр стандарта»](standard.md) генерируется из кода: поля, заголовки, типы, уровни доверия и ограничения размера. Машиночитаемая копия — [`provider_standard.g.json`](../../../provider_standard.g.json).

## Минимальный ответ

```http
HTTP/1.1 200 OK
Content-Type: text/yaml; charset=utf-8
Content-Disposition: attachment; filename*=UTF-8''Example%20VPN
Subscription-Userinfo: upload=0; download=2147483648; total=107374182400; expire=1798761600
reclash-servicename: Example VPN
reclash-supporturl: https://t.me/example_support
reclash-autoupdateinterval: 720

proxies:
  - name: Germany
    type: socks5
    server: de.example.net
    port: 1080
proxy-groups:
  - name: Proxy
    type: select
    proxies: [Germany]
rules:
  - MATCH,Proxy
```

## Совместимость

- Читаются и заголовки других клиентов: `Subscription-Userinfo`, `Content-Disposition`, `profile-title`, `profile-update-interval`, `profile-web-page-url`, `support-url`, `announce`, `hide-url`.
- Заголовки `flclashx-*` читаются только с пресетом FlClashX ([«Имена FlClashX»](headers.md#flclashx-names)).
- Пресет может представить ReClash другим клиентом ([«Пресеты клиента»](request.md#client-presets)). Он никогда не включает идентификатор устройства.
