# Support

ReClash is maintained as an open-source application. Support is best effort, and the project cannot troubleshoot provider accounts, sell subscriptions, recommend services, or recover provider credentials.

## Before asking for help

1. Update to the latest published ReClash build.
2. Check whether the profile works in another current mihomo client.
3. Reproduce the problem with the smallest possible configuration.
4. Search existing issues and pull requests when repository Issues are enabled.
5. Collect the ReClash version, operating system, architecture, exact steps, and relevant debug log lines.

Use the bug report form for reproducible application problems and the feature request form for a concrete user need. The [Telegram channel](https://t.me/ReClashNews) publishes project news; it is not a private support desk.

## Share logs safely

Logs and profiles may contain server addresses, subscription URLs, access tokens, local paths, IP addresses, DNS names, and application activity. Before posting them:

- remove credentials and subscription URLs completely;
- replace server addresses and personal identifiers with obvious placeholders;
- keep only the time range around the problem;
- paste text into the issue instead of uploading an unreviewed archive;
- never publish a full configuration unless you have audited every field.

For suspected vulnerabilities, stop and follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
